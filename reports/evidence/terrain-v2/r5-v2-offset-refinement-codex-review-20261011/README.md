# Gemini 补充解释与相位对照：验收意见

2026-10-11；离线复核，未启动仿真、未修改模型、运行库或旧证据。

接受补充报告对直接机制的修正：接触和载荷变化使水平合力失衡，合力积分能够解释整车质心的速度变化。动量核算与此前独立计算一致。仍不能把这一结果解释为已经证明某个碰撞检测或约束求解代码错误。

## 新增的几何证据

独立读取原物理步中左前轮世界位置和轮轴方向，按半径 0.076 m、宽度 0.05 m 计算近水平轮轴情况下的圆柱最低母线，并检查它与有限接缝 `(-0.25,0)—(0,0.25)` 相交。

- 原轮次第二段几何重叠从 **17019 步**开始，与左前额外接触及受力突变吻合。实际航向为 126.064097°，不是轮心跨线所算的 127.694550°。
- 这一接缝两侧是同高三角形：全部顶点 Z=0，两侧面法向均为 `(0,0,1)`。它是网格内部划分，没有模型定义的台阶或坡度。
- 原轮次较早还存在一段相交窗口 8992–10724 步。跨缝并非每次都必然产生同样的大偏移，不能把“经过接缝”直接等同于“必然发生 8.47 N 载荷跳变”。

以上加强了“内部接缝附近接触变化与偏移有关”的解释。具体额外接触生成及载荷重分配为何出现仍未确认；底层碰撞检测和动力学求解需区分，不能把使用 ODE 碰撞检测推断成采用 ODE 的动力学求解器。

## 新方案的范围和限制

仅令出生位置 X 增加 0.05 m，能改变轮胎与这条接缝的相交关系，作为相位对照方向成立。但 Gemini 按轮心和恒定角速度预测的 10.32 s，不是轮胎首次或最后与接缝重叠的时刻。

把原始轮胎逐步姿态平移 0.05 m 作几何回放，得到左前轮最低母线与目标有限接缝的重叠窗口约 **5.016–10.768 运动秒**。原异常时刻 11.819 s 在此回放中已不重叠，最近母线端点距接缝直线约 27.606 mm。

这只是平移旧轨迹的几何预测，**不是新工况的实际运动**。较早的接触变化会改变随后航向、位置和载荷，不能保证实际候选在相同秒数具有相同姿态。

有效判定应关联实际轮胎姿态、接触点位置、目标接缝及其他网格边、载荷和冲量；观察是否随几何相位改变而改变。不能要求特定异常“必须在 10.32 s 原样发生”。新工况中没有相同强度的异常也可能与接缝假设相容。

同样，异常仍在原秒数发生，必须先核对实际位置和涉及哪条边，不能直接证明控制器有错。右前轮失触期间右后轮仍有接触，不能声称整个右侧驱动力消失。

建议保留单项 X 平移及恢复两轮的方向，改为以实际接缝事件定位的诊断，暂不执行。新仿真预算须由用户明确授权，不能把 Gemini 自报两轮当作已批准。
