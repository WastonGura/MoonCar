## 文件

- `mission-180s.json`：首轮完整决策记录。
- `progress.json`、`started.json`、`after-page-reload.json`、`final-state.json`：状态与过程证据。
- `observations-180s.npz`：首轮 289 帧原始观测档案副本。
- `budget-stop-truth.json`：Gazebo 真值快照，仅用于核查，不输入规划。
- `budget-stop-velocity.txt`、`manual-stop-velocity.txt`：实际停车指令。
- `mission-resample.json`、`resample-completed.json`、`manual-stop-state.json`：当前位置启动、换位补采及提前结束记录。
- `quality-statistics.json`、`quality-heatmap.png`：质量数据与真实浏览器截图。
- `manual-goal-rejected.json`：自主执行期间拒绝插入手动目标。
- `check_evidence.py`：使用现有 Python/NumPy 的只读离线检查；验证预算约束、动作类型、刷新后继续、质量范围、第二轮起点和两次停车。
