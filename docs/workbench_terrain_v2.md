# Terrain V2 工作台场景

当前还可选择 **Terrain V2 · 30×30 米 · 原始地形**（`survey_v2_native`），不追加四根标柱。原生水平激光在原点没有有效回波，不能套用标柱场景的定位结果；新增 RGBD 实验路径和未完成的验证见 [RGBD 说明](rgbd_metric_localization.md)及[修复报告](../reports/LOCALIZATION_EXPANSION_REPAIR_20261021.md)。定位选择由服务启动配置决定，不能仅凭场景名称推断。

在“仿真实验设置”的“地形场景”中选择 **Terrain V2 · 30×30 米 · 定位标柱**，再设置起点并应用。坐标范围为 -15～15 米，“选择全场”、拖框、任务保存和载入均跟随场景。旧任务未写 `scene` 时仍选择原标准场景；V2 的任务标识为 `scene: "survey_v2"`。

本次场景保留 `mooncar_survey_v2.sdf` 的原始地形网格、表面参数、月球重力和 DART 物理配置。当前原配置车辆的水平激光高约 0.365 米，原 V2 场景最高碰撞地物约 0.251 米，原点处缺少可用的水平回波。因此仅在工作台生成的场景中追加四个 **1×1×1 米真实静态标柱**，中心 XY 分别为 `(-7,-5)`、`(-7,4)`、`(3,7)`、`(8,-1)`，避开两处实测地形 patch。标柱具有视觉和碰撞几何，能被实际激光与导航地图观测；其坐标不会输入定位匹配器。此配置明确命名为 `terrain_v2_workbench_markers_v1`，不代表无标柱的原生 V2 定位验证。

起点需有完整地面支承，并避开岩石、碎石、标柱和明显坡面。创建前按实际碰撞三角面检查足迹、坡度和起伏，选取初始高度；这是创建时的坐标约定，运行中的控制和建图只接收传感器数据。推荐先用 `(0,0)`、朝向 `0°` 的平地起点。场景使用原车辆及质量联锁，不自动切换 R5。下列首次接入试验使用当时的 direct 默认配置。

需要完整构建并加载 ROS 工作区，且具备通过版本／校验和检查的项目 DART 运行时。世界名、初始高度和 ogre2 渲染器会传到模拟器与 GUI；资源缺失或安装副本过期时服务会拒绝启动。更新后应先结束旧实验，再重启工作台前后端。已有实验档案保留，新实验的 `scene-setup.json` 和档案来源注明实际场景及追加设施；原生 V2 为零根追加标柱，兼容场景为四根。

首次接入完成八包构建、43 项场景／启动／工作台／自主边界／默认定位回归，以及实际 V2 冷启动、健康定位和首批深度采集检查。实验为 `experiment-4d7d7f36148b`，从原点静止启动；启动记录见 `tmp/ros_acceptance/workbench-terrain-v2-20261020`。

后续在同一实验运行了 180 仿真秒预算、3 米活动半径的 `surface_view_v2` 自主探测。74.5 秒后无新安全候选而结束，3 次前进换位、1 次转向均成功，定位故障计数为零。7917 个原始真值样本全部匹配同时间 TF，XY 误差 P95 为 0.753 厘米、最大 0.939 厘米；新增 132 帧。证据及图表见 `tmp/ros_acceptance/v2-autonomy-20261020-01`。这是 V2＋标柱配置的局部表现；采集末帧早于任务结束约 3.2 仿真秒，不能把采样质量收益当作终点瞬时地图精度。固定初始参考的可见范围、二维水平过滤和坡上适用边界仍需遵守；原生无标柱、30 米全场、坡上行驶和实车能力仍需专项验证。
