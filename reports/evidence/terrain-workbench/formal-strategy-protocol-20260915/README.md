# MoonCar 三策略正式对照协议 v2

本协议恢复原完整设计：3 个场景、每场景 2 个起点、3 种在线策略、每个条件重复 3 次，共 54 轮；每轮预算 90 仿真秒、半径限制 8 米。

三种策略共用 Gazebo 物理、传感器、SLAM、Nav2、安全限制、记录链和 `mapping-acceptance-v1`。批量运行关闭 Gazebo GUI 与异步现场截图以减少主机负担；同步原始深度、坐标契约、地图和评价报告保持启用。该运行差异不改变研究条件。

2026-09-14 的旧批次因主机性能中止，整批排除。本批次使用新目录从第 1 轮重新开始，不混用旧批次的 4 个完整结果。

分析仍以 6 个“场景×起点”条件为单位，先汇总每个条件的 3 次重复，再比较策略。报告 S、C、P、原始观测覆盖率、高程 RMSE、坡度 MAE、耗时、路程、动作失败和终态。失败、不可评价和负面结果全部保留，不因成绩调整策略、阈值、场景或预算。

运行入口为 `run_formal.sh`。预计持续数小时；运行时电脑仍可能明显变慢。
