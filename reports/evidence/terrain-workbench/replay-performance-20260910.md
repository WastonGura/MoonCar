# 离线回放卡顿修复检查

日期：2026-09-10。Windows 本地 Python + 用户 Chrome，181 帧 Gazebo 观测档案 `survey-20260909T151316328964Z.npz`；不是实车或其他设备性能保证。

## 原因与修改

- 原版每个进度输入并发请求一次从零融合；旧响应虽被丢弃，服务器仍继续计算。播放等待整次读取后，再额外等待 350 ms。
- 现版拖动防抖 100 ms，最多一个请求在途，替换尚未处理的目标；独立播放序号防止暂停/继续后旧循环重新启动。
- 后端复用完整档案、增量推进当前回放位置，并缓存最近 4 个快照。版本变化重新载入；回退未命中缓存时重建前缀。
- 地表按实际样本与观测次数复用拟合，风险边框合并为一个 LineSegments。保留每个时刻的观测边界与原有规划安全判据。
