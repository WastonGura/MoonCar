## 二、 仿真实验设计体系（自变量考量）

1. **自变量 1：地形几何复杂度（三大地貌）**
   - **`visible_ramp_v1`（单向斜坡）**：$10^\circ \sim 15^\circ$ 连续上坡，地面平缓无剧烈视线遮挡，考察爬坡滑移对测绘质量的影响；
   - **`visible_curve_v1`（复合弯道坡面）**：复合空间曲面起伏，多山脊与低洼盲区，考察在视野死角多、路径频繁绕行条件下的避障与探索能力；
   - **`survey`（开阔全景平原）**：50×50 米大尺度场地，散布岩块与陨石坑，考察大范围巡航与远距离视线可达性。

2. **自变量 2：自主探测决策策略（六大策略）**
   - **v3 系列（双自由度云台解耦策略）**：
     - `nearest_view_v3`：就近视场优先，高频利用云台扫盲；
     - `coverage_view_v3`：覆盖面积优先，全局未遮挡视场增益最大化；
     - `surface_view_v3`：地表补采优先，定向补采视线死角与高粗糙度地表。
   - **v2 系列（传统底盘转向基准策略）**：
     - `nearest_view_v2` / `coverage_view_v2` / `surface_view_v2`：依赖底盘差速转向提供视场偏航。

3. **自变量 3：时间跨度 $t$（连续演化与离散断面）**
   - **时间横坐标的科学价值**：识别前 60s 的“态势感知爆发速度”，量化 180s 后的“边际效益递减拐点”，为实机任务提供最佳能耗/时间截断依据；
   - **离散时间里程碑**：选取 `30s`、`60s`、`120s`、`180s`、`240s`、`300s` 六个典型时间节点。

## 三、 关键 Bug 根因与修复验证

- **问题现象**：早期测试中 v3 策略运行仅 15~20 帧，且在 60~90 秒即发生停机。
- **根因分析**：双轴云台向后扫描时拍摄到了月球车自身后甲板、太阳能板和后轮（提取确认有 22,379 个点落在车体内）。`terrain_node.py` 将车体误分类为致死障碍，导致 Nav2 代价地图将月球车当前位置标为致死代价（Lethal Cost 254），底盘尝试起步时被拒绝，连续 3 次熔断导致过早退赛。
- **修复措施**：在 `terrain_node.py` 引入车体 3D 几何包络自滤波（Self-Filtering），准确剔除车身与车轮点云，保持原生观测点云完整无篡改。
- **修复成效**：
  - **弯道场地 (`visible_curve_v1`)**：`coverage_view_v3` 跑满 **297.2 仿真秒**，帧数跃升至 **220 帧**，行驶 **17.99 米**，覆盖面积达 **165.56 m²**，彻底解决死锁！
  - **全景场地 (`survey`)**：`coverage_view_v3` 跑满 **294.1 仿真秒**，帧数达 **226 帧**，行驶 **16.99 米**，覆盖面积达 **166.88 m²**。

## 五、 为什么单位位移收益曲线 $\eta(t)$ 证明了 v3 策略的决定性优势？

表面上看，若仅对比 300 秒时的**绝对建图面积**（例如弯道场景中 v2 为 174.25 m²，v3 为 165.56 m²），容易产生“v3 似乎不如 v2”的错觉。但通过本次生成的**单位位移收益时序演化曲线**（`displacement_efficiency_curves.png` 与 6 维 `time_series_curves.png`），揭示了两者在物理能耗、探测安全和运动机理上的本质差距：

### 1. 指标定义与物理意义
- **单位位移观测收益 $\eta(t) = \frac{S(t)}{L(t)}\;(\text{m}^2/\text{m})$**：每驱使月球车底盘移动 1 米，所换回的全局有效观测投影面积；
- **单位位移拟合收益 $\eta_{valid}(t) = \frac{S_{valid}(t)}{L(t)}\;(\text{m}^2/\text{m})$**：每驱使底盘移动 1 米，所换回的高精度有效连续地形表面积。

### 2. 时序演化规律对比

1. **初始阶段 (0 ~ 50s)：原地扫盲 vs 狂暴掉头**
   - **v2 策略**：由于传感器固定在车架正前方，为了获取周围视野，底盘必须原地频繁差速自旋 $360^\circ$ 并短途冲刺。在真实月表中，这种行为极度危险，且造成里程 $L(t)$ 迅速增加，其位移收益曲线 $\eta(t)$ 发生断崖式暴跌；
   - **v3 策略**：双自由度云台仅依靠毫瓦级伺服电机进行俯仰与偏航扫描，底盘几乎完全静止（$L \approx 0$），在 0 能耗位移的前提下瞬间建立全向初始态势感知。

2. **稳态巡航阶段 (100s ~ 300s)：高能效稳定巡航 vs 边际收益枯竭**
   - **覆盖优先 v3 (`coverage_view_v3`)**：
     - 在起伏弯道场景 (`visible_curve_v1`) 中，底盘始终保持克制平顺的巡航，最终以 **17.99 米** 的位移换取了 **165.56 m²** 覆盖与 **129.44 m²** 高质量有效表面，稳态位移效率收敛于 **9.20 m²/m**；
     - 在开阔全景平原 (`survey`) 中，以仅 **16.99 米** 的行驶里程换取了 **166.88 m²** 覆盖，最终位移效率收敛于 **9.82 m²/m**。
   - **激进的 v2 策略 (`surface_view_v2` / `coverage_view_v2`)**：
     - 在弯道场景中底盘狂奔了 **23.34 米**，在全景场景中更是长途奔袭了 **28.21 米**；
     - 随着底盘频繁大角度调头、重复碾压已知区域，其 $\eta(t)$ 持续单调剧烈衰减，最终分别跌落至 **7.46 m²/m**（弯道）和 **6.09 m²/m**（全景）。
   - **核心结论**：在复合弯道与开阔平原中，**v3 的单位位移探测收益比 v2 分别高出 +23.3% 与 +61.2%！**

### 3. 月球表面真实物理约束（为什么高里程是致命劣势）
在真实地外探测（如嫦娥/玉兔号）中，“多跑几米”绝非免费的午餐，而是巨大的工程风险：
1. **月壤剪切与下陷陷车（Wheel Sinkage）**：月球表面覆盖极度松散、多孔的风化层月壤，微重力（1/6g）下车轮附着力低。原地大角度频繁差速转向极易刨坑致使底盘托底陷车。v2 的高频转向在真实任务中是不可接受的；
2. **整车能耗与热预算瓶颈**：底盘大功率驱动轮电机能耗是云台伺服电机的数十倍。v3 将“转底盘”解耦为“转云台”，大幅降低了机械磨损与动力电池峰值放电负荷；
3. **定位漂移发散（Odometry Drift）**：月壤滑移率高达 20%~40%，底盘运动越剧烈，轮式里程计发散越严重。v3 的低位移策略极大降低了位姿累计误差。

## 六、 核心启示与工程落地建议

1. **位移收益决定成败**：衡量行星漫游车自主探测策略，绝不能单纯看终点面积，**“单位位移探测收益 $\eta(t)$”才是衡量策略智能水平与系统能效的黄金法则**；
2. **任务截断黄金窗口**：所有策略在前 120 秒内均建立了 70%~80% 的全局地形感知；后 120 秒（180s~300s）仅贡献 15%~20% 的边缘收益。在实际飞行任务中，**将单次连续探测窗口截断在 120~180 秒是最优能耗决策**；
3. **策略选型指南**：
   - **大范围主航道探索**：首选 **`coverage_view_v3`**，兼具最高空间收益与最克制的底盘机动；
   - **局部科学目标精细建图**：首选 **`nearest_view_v3`** 或 **`surface_view_v3`**（配合前向视场局部补光/补点）。
