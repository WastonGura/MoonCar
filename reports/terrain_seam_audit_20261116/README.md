# V2 地形拼接质量审查

2026-11-16。只读审查当前实际碰撞三角形，没有修改地形、显示方式、导航保护或历史实验。

检查两块实测地形的四条边，以 2 cm 间隔比较双方同一点的高度、边缘两侧实际三角面坡度，并统计 35 cm 混合带。采样器先通过解析平面自检。18° 仅用于对照当前地形分类器的阈值，不是要求自然地形全部低于该值。

右下块最陡的混合带位置约为 `(3.183, -7.883)`。原始实测数据中相同格子的两个三角面坡度约为 6.11° 和 5.64°，拼接后的实际坡度最高为 49.83°。因此，该处存在拼接引入的陡坡，不只是绘图的等高线或配色问题。

生成器把实测高度与人工背景在 0.35 m 带宽内混合。高度差较大时，窄带需要在很短距离内补足高度差，会产生额外陡坡；边缘高度接上并不保证过渡带的坡度合理。背景与细块的网格间隔也不同，应检查共边插值及坡度连续性。

这种构造会影响过坡、通行性判断、规划和车轮接触的可信度。它尚不能证明此前某一次停车就是该接缝造成；过去两种策略的对照只代表在该版本场景中的表现，不能直接当作实车或自然月面能力验证。

整改应保留当前 V2 和证据，另做可追溯的新地形版本。重点是用统一的整体地形衔接实测区域、根据高度与坡度匹配设计过渡，而非固定窄带硬接；保留原始坑坡的真实起伏。发布前需要检查实际碰撞网格的接缝、额外陡坡、支撑与接触，以及视觉和物理模型的一致性。

`audit.py` 可重算，`summary.json` 保存数值与场景/数据 SHA256，`edge-samples.json` 保存逐点边界检查。此审查不是轮胎接触、牵引力或实车验收，当前版本尚未修复。
