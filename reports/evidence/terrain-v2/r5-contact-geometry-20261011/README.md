## 已确认的工具问题与修正

库采样在墙钟1791672659.553秒取得，实际首步元数据在1791672665.045秒写入。采样时contact、axle、turn和metadata库已加载，但逐步观察库尚未出现在该快照中。旧入口把第一次非空回执永久缓存，即使passed=false也停止采样，最终因此拒绝资格。后续完整逐步记录存在，不用于倒填当时的库路径及哈希。

在同容器中进行**无Gazebo、无世界、无ROS participant**的真实dlopen对照：先加载contact/axle/turn/WheelSlip库，再延迟0.7秒加载origin-observer。原回执先不完整、后完整；新Readiness仅接受passed严格为true的完整回执，保留两次历史。候选与实际未来源码两次离线检查均通过。4项回归覆盖缺失、错误标记、PID更换、队列上限与历史保留。

本轮冻结的139项执行源码已逐项复制并核验，冻结结束标记仍为unchanged=true。**停止后**才修正独立测试入口，新增有界回执历史、持续采样及异常时子进程收尾；正式启动、模型、摩擦、控制与DART未改。`poststop-receipt-repair.json`保存旧/未来入口哈希。修正后新增仿真0次，因此仅验证了工具修正，未验证新物理矩阵。
