## 4. 动力学因果链分析：从网格接缝到整车动量

### 4.1 目标接缝交会时序与突变对应
- 目标接缝定义：线段端点为 $(-0.25, 0.0)$ 到 $(0.0, 0.25)$，直线方程 $y - x = 0.25$。
- **恢复原点（第 2 轮）**：
  - FL 轮底母线第一次跨越该接缝：迭代 8992～10724 ($t = 3.791 \sim 5.523\text{ s}$)；
  - FL 轮底母线第二次跨越该接缝：迭代 **17019～17224** ($t = 11.818 \sim 12.023\text{ s}$)；
  - **因果链条**：车轮在迭代 17019 精确切入接缝 $\rightarrow$ FL 接触点突增至 3 点 $\rightarrow$ 迭代 17020 FL 产生 1 步瞬态空快照 $\rightarrow$ 对侧 FR 轮在 17022 失去接触（持续悬空 241 步）$\rightarrow$ 车辆四轮载荷剧烈失衡 $\rightarrow$ 产生巨大的负向 $X$ 轴水平接触反力（累积冲量 $-0.0246\text{ N}\cdot\text{s}$）$\rightarrow$ 驱动整车质心向 $-X$ 与 $-Y$ 方向漂移 10.286 mm。
- **平移 +5cm（第 1 轮）**：
  - 出生 $X$ 平移 +5cm 后，旋转轨迹相对网格偏移，FL 轮仅在迭代 **10077～15404** ($t = 4.876 \sim 10.203\text{ s}$) 与该接缝相交；
  - **在迭代 17019 附近，车轮完全不经过该接缝**，原点的恶性断序、FR 241 步悬空和对角载荷突变均未发生；
  - 最终漂移位移显著减小至 5.964 mm，峰值位移降低至 8.501 mm。

### 4.2 动量定理物理闭合验证
根据牛顿第二定律动量定理：
$$\Delta \mathbf{p} = m \Delta \mathbf{v}_{CoM} = \int_{t_0}^{t_1} \mathbf{F}_{xy}^{ext} dt = \mathbf{I}_{xy}$$
代入整车实测总质量 $m = 9.186\text{ kg}$：
- **第 1 轮（平移 +5cm）**：
  - 冲量理论推导速度变化：
    $$\Delta v_{x, theo} = \frac{-0.0014648\text{ N}\cdot\text{s}}{9.186\text{ kg}} = -0.15946\text{ mm/s}$$
    $$\Delta v_{y, theo} = \frac{+0.0107714\text{ N}\cdot\text{s}}{9.186\text{ kg}} = +1.17258\text{ mm/s}$$
  - 物理步实测质心速度变化：
    $$\Delta v_{x, actual} = -0.15935\text{ mm/s}, \quad \Delta v_{y, actual} = +1.16934\text{ mm/s}$$
  - **相对守恒误差 $< 0.27\%$**！
- **第 2 轮（恢复原点）**：
  - 冲量理论推导速度变化：
    $$\Delta v_{x, theo} = \frac{-0.0246330\text{ N}\cdot\text{s}}{9.186\text{ kg}} = -2.68158\text{ mm/s}$$
    $$\Delta v_{y, theo} = \frac{-0.0023842\text{ N}\cdot\text{s}}{9.186\text{ kg}} = -0.25955\text{ mm/s}$$
  - 物理步实测质心速度变化：
    $$\Delta v_{x, actual} = -2.68147\text{ mm/s}, \quad \Delta v_{y, actual} = -0.26278\text{ mm/s}$$
  - **相对守恒误差 $< 0.01\%$**！
- **结论**：接触水平力的物理积分与整车动力学速度跳变完美吻合，证明水平力失衡是车体发生位移的直接动力学原因。

## 5. 混杂因素与当前认识局限

1. **初始静置载荷的混杂影响**：
   - 出生位姿平移 +5cm 不仅改变了车轮几何相对于三角接缝的运动轨迹，同时也改变了出生时静置四轮在三角网格各顶点/平面上的落点分布；
   - 实测名义静置载荷（Parked Nominal $F_z$）：
     - 第 2 轮（原点）：FL 4.34 N, FR 2.81 N, RL 3.10 N, RR 4.64 N（呈现明显的 FL-RR 对角对承载）；
     - 第 1 轮（平移）：FL 3.24 N, FR 3.91 N, RL 4.31 N, RR 3.43 N（呈现相反的 FR-RL 对角对承载）；
     - 因此，平移带来的位移改善中，包含了“接缝交会时序重构”与“初始静态载荷分布改变”的综合作用，后续若需严格单因素剥离，需要无接缝参考系下的载荷对称性标定。
2. **微观碰撞求解机制未隔离**：
   - 两轮实验确认了接缝的空间位置能确定性地激发接触点数跳变与受力失衡；
   - 但不能由此直接给 DART 碰撞求解器（如 ODE contact generation、LCP Lemke/Dantzig 算法）定性特定 bug。此部分需要源码级的离线接触测试桩进一步验证。
