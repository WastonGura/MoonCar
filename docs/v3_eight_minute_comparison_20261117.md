2026-11-17。在 `dev/terrain-mapping-workbench` 上继续，保留已完成的短轮数据。原策略 `baseline` 与邻域策略 `elevation_neighborhood_v1` 各新建一个世界，使用同一原生 V3、R5、`rgbd_window` 定位、起点 `(0.5,0,0)`、480 仿真秒预算、7200 墙钟秒采集上限、不设起点半径。原有场地边界、安全检查、定位参数、动作选择与无主动定位回访的设置不变。

顺序运行，定位 CPU 0–1、物理 CPU 2–5、GUI/录屏 CPU 5，数值库单线程，每墙钟秒采集3帧真实 GUI。采集期间不运行离线视频合成，中途不修改产品源码。任务如出现定位故障、无候选、安全停车或墙钟到限，保留实际停止结果，不强行续跑、不在本轮调参重试。剩余时间不足以完成下一动作时可正常提前收尾，实际时长另列。

除全程数据外，按任务开始后每分钟记录累计观测、有效高程、轨迹长度和定位误差，并单独比较前后4分钟的新增测绘与重复运动。报告本次持续能力、实际中断与收尾原因；一次8分钟试验不等于全场覆盖或实车可靠性认证。
