# V3 两种地形策略：自主探测与测绘质量对照

2026-11-17。原策略 `baseline` 与邻域候选 `elevation_neighborhood_v1` 各运行一次自主探测。使用同一原生 V3、R5、起点 `(0.5,0,0)`、180 仿真秒预算、2400 墙钟秒采集上限、无起点半径、相同资源分配和每墙钟秒 3 帧实际 GUI 录屏。定位、回访和导航保护不改，默认地形策略不替换。墙钟上限仅是采集限额，V3 使用更细地形网格，仿真时间预算不变。

重点是测绘成果：被动观察器记录 `/mooncar/map/quality` 的真实高程拟合格及接收墙钟，单独保存为 `survey-map.jsonl`。不把导航代价图当作测绘地图，不使用最终地图回填早期录像。两组期间不同时运行离线合成。

参考地图由实际 V3 碰撞地面和岩石/碎石几何构建，独立于小车重建。对照统一坐标、范围、比例和高程色标；未观测格留空，拟合失败和混合表面另标。高度差只对有估计且有对应参考的格计算，参考范围外的实际观测仍计入总面积，另记未评分数量。主要精度统计区分单表面和岩石边缘混合格。

沿用任务声明的世界坐标与初始摆放，不用真值轨迹修正小车地图，也不做最佳拟合配准或补洞。高程误差包含定位、传感器及单高程表面表示的共同影响，不宣称是纯深度传感器误差。完整参考只用于离线评价和图示，不输入控制。

视频保留两组实际探测过程、随车导航图与四轮状态；另展示环境高程基准、两组实测高程与各自的高度差。地图选择必须早于对应实际画面接收时刻和显示仿真时刻。另交付可放大的最终五图对照及统计。单轮运行不能估计成功率或断言普遍优劣。
