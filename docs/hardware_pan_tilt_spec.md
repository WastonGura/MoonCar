# 月球车双自由度观测云台（Pan-Tilt）硬件设计与选型规范

> **版本**：v1.0 (2026-09-18)  
> **适用机型**：MoonCar 四驱滑移轮式月球探测车  
> **核心目标**：实现深度相机（OAK-D Lite / RealSense D435i）视场角与底盘运动解耦，彻底避免在崎岖松散地形下因车体原地滑移转向导致的剧烈滑移打滑、车轮刨沙沉降与低掠射角失效。

---

## 一、机构设计与运动学指标

### 1.1 自由度与行程范围
云台采用两自由度（2-DOF）正交串联构型：
- **水平偏航轴（Pan Joint）**：
  - 旋转轴：沿车体垂直方向（URDF: $Z$ 轴）
  - 物理行程极限：$\pm 135^\circ$（总计 $270^\circ$ 全景扫描角）
  - 软件控制死区/限位：$[-2.356, +2.356]\text{ rad}$
  - 零位基准：相机正朝车头前方（$+X$ 方向）
- **垂直俯仰轴（Tilt Joint）**：
  - 旋转轴：沿车体横向（URDF: $-Y$ 轴，正角仰头、负角低头）
  - 物理行程极限：$-35^\circ \sim +15^\circ$（俯角 $-35^\circ$ 探测车前近处坑洼，仰角 $+15^\circ$ 观测坡顶远景）
  - 软件控制范围：$[-0.611, +0.262]\text{ rad}$
  - 默认巡航位（Home/Homing）：$-15^\circ$（$-0.2618\text{ rad}$），保持俯视车前 1.5~3m 地表。

### 1.2 运动性能与控制参数
- **最大输出转速**：$\ge 360^\circ/\text{s}$（硬件物理指标）
- **软件平滑限速**：$1.5\text{ rad/s}$（约 $86^\circ/\text{s}$），防止相机快速旋转引起的剧烈运动模糊（Motion Blur）与点云拖影。
- **定位回馈与精度**：12 位无接触磁编码器（分辨率 $0.088^\circ$），闭环绝对位置反馈。
- **承重与力矩校核**：
  - 负载重物：OAK-D Lite（约 61g）+ 相机转接支架（约 25g）$\approx 86\text{g}$。
  - 质心力臂：约 $40\text{mm}$。
  - 重力最大静态负载力矩：$0.086\text{ kg} \times 9.8\text{ m/s}^2 \times 0.04\text{ m} \approx 0.034\text{ N}\cdot\text{m} = 0.34\text{ kg}\cdot\text{cm}$。
  - 选用舵机堵转力矩：$\ge 15\text{ kg}\cdot\text{cm}$（安全裕度 $>40$ 倍，在车辆剧烈震动、颠簸时具有极高机械刚度，不发生抖动）。

## 二、执行器选型方案（串行总线舵机）

推荐优先采用**串行总线高压磁编码伺服舵机**方案，相比传统模拟 PWM 舵机具有绝对位置回读、单总线菊花链走线、电流与温度监测等关键优势。

### 2.1 主选型号：飞特（Feetech）STS3215 串行总线舵机
- **工作电压**：$6.0\text{V} \sim 8.4\text{V}$（额定 $7.4\text{V}$，匹配车载 2S 供电或 12V 降压）
- **堵转扭矩**：$19.5\text{ kg}\cdot\text{cm} @ 7.4\text{V}$
- **空载转速**：$0.165\text{s} / 60^\circ @ 7.4\text{V}$
- **传感器**：12 位高精度磁编码器（360° 可多圈，可设定机械限位）
- **通信接口**：TTL 单线串行通信，半双工，波特率最高支持 1 Mbps
- **保护特性**：堵转保护、过温报警、过流过压保护

### 2.2 备选型号
1. **备选 1：飞特 SCS15**
   - 经济型金属齿串行舵机，扭矩 $15\text{ kg}\cdot\text{cm}$，精度与稳定性略低于 STS 系列，成本更低。
2. **备选 2：Robotis Dynamixel XL430-W250-T**
   - 工业级串行舵机，ROS 2 官方支持库成熟，支持 11.1V 直供电，但单价较高（约 ¥450/台）。

## 三、电气与供电拓扑

### 3.1 供电架构设计
为防止舵机大动态加减速引起的电压跌落干扰树莓派主控与 IMU 传感器，采用**电源分路隔离**：
- **主电源输入**：车载 12V 锂电池组（3S Li-Po 或 12V 动力锂电池）。
- **云台专用 DCDC 降压模块**：
  - 输入：12V
  - 输出：$7.4\text{V}$，额定持续电流 $\ge 3\text{A}$，峰值电流 $\ge 5\text{A}$（推荐 XL4015 或高频同步整流降压模块）。
  - 输出端并联一个 $1000\mu\text{F}$ 低 ESR 电解电容吸收舵机反电动势。
- **共地要求**：车载 12V 地、7.4V 舵机地与树莓派 5V/GND 必须单点共地。

### 3.2 控制信号链路
- 树莓派主控 USB 端口 $\to$ **飞特 URT-1 总线调试转接板**（USB 转 TTL 串口，板载硬件半双工自动切换电路）。
- URT-1 输出 TTL 信号端（TX/RX/GND）$\to$ 首台 Pan 舵机 $\to$ 菊花链直通 $\to$ Tilt 舵机。
- 舵机 ID 配置：Pan 轴设为 `ID 1`，Tilt 轴设为 `ID 2`。

## 四、机械结构与线缆防护

### 4.1 支架选型与装配
- **底座固定**：铝合金标准短 U 支架固定在 MoonCar 车体上顶板（坐标原点 $x=0.18\text{m}, y=0.0\text{m}, z=0.28\text{m}$）。
- **转折构件**：铝合金多功能长 U 支架连接 Pan 舵机输出法兰与 Tilt 舵机机身。
- **相机安装板**：
  - 3D 打印轻量化碳纤/PETG 转接件（或 CNC 铝板）。
  - 预留 OAK-D Lite 专用标准相机螺丝孔（1/4 英寸接口及 4×M3 螺丝背孔）。
  - 背部预留 USB Type-C 弯头走线卡槽与线缆去应力夹（Strain Relief）。

### 4.2 线束与月尘防护
- **U 型弯折防缠线走线**：
  - 深度相机的 USB 3.0 Type-C 线采用超柔硅胶短线（长度 30~50cm，弯头接口）。
  - 相机线与舵机电源线在旋转轴处留出半径 $\ge 35\text{mm}$ 的 U 型松弛环，固定在 Tilt 臂导线槽中。
  - 经实物角度测试，$\pm 135^\circ$ 极限旋转时无任何拉扯或打结现象。
- **防尘密封**：
  - 针对月表模拟沙尘环境，舵机转轴接缝处加装硅胶密封波纹圈或 O 型防尘圈。
  - 避免沙粒直接侵入齿轮箱轴承。

## 六、与 ROS 2 软件栈接口对应关系

| 硬件信号/物理量 | 对应 ROS 2 话题 / 参数 | 对应驱动节点 / 仿真控制器 |
| :--- | :--- | :--- |
| 水平偏航角（Pan） | `/mooncar/cmd_camera_pan` (`std_msgs/Float64`) | `pan_tilt_controller.py` $\to$ Gazebo / 串口驱动 |
| 垂直俯仰角（Tilt） | `/mooncar/cmd_camera_tilt` (`std_msgs/Float64`) | `pan_tilt_controller.py` $\to$ Gazebo / 串口驱动 |
| 编码器关节状态回读 | `/joint_states` (`sensor_msgs/JointState`) | `robot_state_publisher` 发布动态 TF 变换 |
| 坐标变换树 | `base_link` $\to$ `camera_mount_link` $\to$ `camera_pan_link` $\to$ `camera_tilt_link` $\to$ `depth_camera_optical_frame` | TF2 动态广播，供 `terrain_node` 与 `rtabmap` 实时投图 |
