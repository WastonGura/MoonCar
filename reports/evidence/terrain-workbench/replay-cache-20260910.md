# 完整离线回放缓存与显示稳定性检查

日期：2026-09-10。工作区：MoonCar-mapping。此前最近 4 帧后端缓存的优化继续保留，本轮新增浏览器完整预缓存。

## 行为

- 选择档案后自动准备当前版本所有帧，含空白第 0 帧。进度在左侧单独显示，帧数输出不再写入“正在载入”或“正在定位”，数字使用固定最小宽度与等宽数字。
- 使用浏览器原生 Cache Storage，刷新后检查版本复用；无需新依赖或数据库服务。最多保存当前一个档案版本、512 MB，内存最多 8 个解码帧。
- 就绪帧跳过过期网络请求，在下一动画帧读取显示；未准备位置继续按需读取。后台预缓存顺序推进，播放时暂停准备，避免抢占交互计算。
- 文件版本、帧序号不匹配时拒绝写入缓存。跟随采集模式读取服务端，避免将离线缓存误作最新采集结果。
- 首次预缓存仍需计算；浏览器清理缓存后需重建。按 350 ms/关键帧展示，未实现视频插值或原始时间戳播放。

## 实际浏览器证据

使用用户 Chrome、`http://127.0.0.1:8877/`、181 帧 Gazebo 采集档案。

1. 后台完成所有帧准备；状态为“回放缓存已就绪 · 181 帧”。缓存响应合计 339,048,342 字节。
2. 刷新页面并重新选择同一档案，完整缓存仍存在，无需重新融合 181 帧。
3. 暂时停止该本地地图服务，页面继续从末帧跳转到第 90 帧，帧数与滑块同为 90。
4. 服务保持停止时继续播放至第 96 帧，逐帧显示正常。期间抽样 12 次帧数文本，均为数字帧数，无载入提示交替。
5. 随后恢复本地服务。本轮未运行车辆导航或改动网络设置。
