# 固定漏斗并行采集与配对步长检查

批次：20260930T223516+0900；继承前批接触和漏斗输入，验证 MPI 全局采集后运行 200 g。另以五个种子进行 32 g 配对步长诊断。**本批未调摩擦、未拟合土壤参数、未修改 R5 场景。**

## 输入与范围

公开文献：Hurrell 等（2025），DOI 10.1007/s11214-025-01164-8，PDF 第 6、8–9 页；已知 Toyoura 实测 200 g、铝板、安息角 34.3±0.8°，DEM 采用 2 mm 球体、ρ=2650 kg/m³、E=5×10⁷ Pa、ν=0.25、恢复系数 0.3。论文 DEM 使用 JKR 与 Type-C 滚动；本批采用非黏聚 Hertz-Mindlin 和 SDS 滚动，模型等价性未知。

漏斗、闸板和测角沿用前批 apparatus.json：出口半径 8 mm、上口半径 60 mm、锥高 80 mm、出口距底板 100 mm。论文这些尺寸、供料方式、砂粒—铝板界面参数和精确图像测角程序未知。粒子静摩擦 0.65、滚动摩擦 0.15、壁面 0.65/0.15 是本批冻结输入，壁面数值不是实测铝板数据。SDS 刚度 1000、阻尼 0 为工程输入。

当前 200 g 只有一个种子；五个配对种子只适用于 32 g，不能写成五次 200 g 重复。单核批与本 MPI 批不能合并为同版重复，粒子布置与浮点轨迹会随执行方式变化。所有槽位在 plan.json 中保留，包括启动失败。

## 计算与测量定义

m_p=ρπd³/6；N=round(M/m_p)，实际 M=N m_p。K_tr=Σm_p|v|²/2，K_rot=ΣI|ω|²/2，I=2m_p(d/2)²/5。q_tr=K_tr/(Mgd)，q_total=(K_tr+K_rot)/(Mgd)。八个径向 45° 扇区，用固定 2 mm 分箱的上轮廓在 0.2R–0.8R 最小二乘拟合 z=a r+b；θ=atan(−a)。R 为该扇区径向距离的 95% 分位。

几何停止：全部粒子球顶已低于漏斗出口，连续三个相隔 0.08 s 样本 q_tr<10⁻⁵；总动能单独判断。几何停止不能证明粒子完全不转。每轮八扇区 SD 是空间差异；五轮 θ 的样本 SD 才是本初始化重复的离散度，s=sqrt(Σ(θ_i−平均θ)²/(n−1))。配对 δ_i=θ_i,4µs−θ_i,8µs，报告平均 δ 与样本 SD，未在看结果后建立过关阈值。

前批 32 g 单种子两步长角差 2.2189°，为区分积分步长和初始布置影响，新增五个固定种子 123457、223457、323457、423457、523457，各运行 8/4 µs。除了种子和步长，接触、几何、质量、粒径及停止规则一致；总共十轮，不代表物理实验。8 g 只有约 2–3 粒径高且轮廓拟合很差，未继续用它作为收敛证明。

## 滚动模型与残留自转

Altair 官方 Type-C 说明：总滚动力矩分非黏性项和黏性项，前者依赖相对转角与滚动刚度，后者依赖相对转速、等效惯量及黏性阻尼比，并受摩擦力矩上限约束。LAMMPS SDS 则用滚动伪力 F=k ξ−γ v，v=−R_eff(Ω_i−Ω_j)×n，并限幅为 μ_roll F_n；力矩为 R_eff n×F。这些输入不能仅因同叫 rolling friction 就逐项照抄。

SDS 当前只对垂直接触法向的相对转动产生滚动阻力；球在水平板上的绕 z 轴自转使上述叉积为零，本批 twisting 默认 none。于是平动停止后仍可能有转动动能。已记录，**没有为让总动能达标临时加扭转阻尼**。这解释该模型的自由度，不证明模型与真实 Toyoura 砂等价。

下一步需核对 Type-C 刚度/阻尼与 SDS 的量纲、接触依赖和扭转处理，先做可追溯的单接触对照；若改变接触律必须新建批次。容重需独立的可比装填装置，不能用砂堆包围盒替代 JIS 容重。FJS 的论文 Pa 黏聚值也不能直接作为 LAMMPS JKR 表面能 J/m²。

官方依据：[Type-C](https://help.altair.com/2023/EDEM/Creator/Physics/Rolling_Friction/Type_C_Rolling_Friction.htm)、[LAMMPS granular 滚动和扭转规则](https://docs.lammps.org/stable/pair_granular.html)、[mpi4py 安装/ABI](https://mpi4py.readthedocs.io/en/stable/install.html)。

## 复算

在本目录执行（新实验必须使用新输出目录）：

```powershell
docker run --rm -v "${PWD}:/evidence" --entrypoint mpiexec.openmpi mooncar-dem:mpi-2025.7.22.4 --allow-run-as-root -n 4 python pile.py --check --expect-ranks 4
docker run --rm -v "${PWD}:/evidence" --entrypoint mpiexec.openmpi mooncar-dem:mpi-2025.7.22.4 --allow-run-as-root -n 4 python pile.py --out new200g --mass-g 200 --seconds 8 --expect-ranks 4
docker run --rm -v "${PWD}:/evidence" --entrypoint python mooncar-dem:mpi-2025.7.22.4 audit.py
```

audit.py 直接读 particles.zip，检查 CRC、逐帧数量/ID/有限值/粒径、终点与 raw 配对，独立复算平动/转动能量及轮廓。run_repeats.py 根据 plan.json 顺序执行十个配对槽位，拒绝已有输出目录，保存每轮日志与退出码。失败启动证据另查 CRC/哈希，不计入完整试次统计。

## 最终结果与边界

本批 14 槽位均结束：13 个完整试次经 raw/终点审计，1 个 MPI 初始化失败单独保留。失败试次整体退出 1，完整单核产物的 CRC/逐帧/终点审核另见 failed-launch-evidence-audit.json，不计入四进程统计。前批 8 完成/1 中断与本批分开。两批 SHA256SUMS 对全部版本化证据核验。

200 g 实际离散质量 200.005098 g，18018 粒子全部保留并出料，装填时漏斗外粒子 0。仿真 5.76 s、主积分墙钟 2275.48 s（不含最终压缩），八扇区平均轮廓角 **28.426187°**，空间扇区样本 SD 1.627263°，最小 R² 0.975264，最高点约 15.055 个粒径。相对论文 34.3° 相差 -5.873813°；装置/测量和接触模型仍未完全可比，不能据此只调摩擦去追目标。

终点平动动能 1.72019073e-13 J、转动动能 1.64991629e-06 J，转动能量中绕 z 分量 0.999999380。几何停止成立，总动能停止不成立；不报告颗粒完全静止或正式物理验证通过。

| 8 µs | 5 | 20.700357° | 0.766452° | 19.797812–21.688168° |
| 4 µs | 5 | 21.370711° | 0.613447° | 20.621748–22.185809° |

配对 4−8 µs 平均角差 0.670355°，配对差值 SD 0.866537°。五个差值依次为 0.823937°、0.367359°、2.104450°、-0.028199°、0.084226°。步长差值与初始化变化都不可忽略；没有预设等效性容差，不能凭均值接近宣布收敛，尤其不能外推到 200 g。

本轮结论：装置可完整装填/释放 200 g，全局粒子采集与能量复算可用；小样诊断不足以确认 200 g 时间步长收敛，接触模型/壁面及论文测角口径仍有缺口。暂未开展参数优化。下一阶段先对照滚动接触规则，再冻结可比装置、独立容重及拟合/验证计划；任何物理输入变更另立时间戳批次，保留此次负面结果。
