# 三策略新评分管线试验协议

这是正式论文对照前的一次有限运行检查，目标是确认三种在线策略在无界面批处理下都能稳定留下原始深度、坐标契约、动作记录和 `mapping-acceptance-v1` 结果。它不用于判断哪种策略更优。

- 场景：`visible_ramp_v1`。
- 起点：`[-1.4, 1.55, -0.3]`、`[6.5, -2.0, 2.4]`。
- 策略：三种在线策略各一次，共 6 轮。
- 每轮预算：30 仿真秒；半径限制 8 米。
- 每轮重新启动 Gazebo、SLAM、地图记录和同步原始数据采集。
- 批量运行关闭 Gazebo GUI 和异步现场截图；传感器、物理、Nav2、安全、策略和评价不变。
- 预计总墙钟 12 至 25 分钟；只是依据现有短样例和旧 90 秒运行给出的调度范围，不是保证。

完成条件是 6 个预声明轮次各自留下终态记录；失败和不可评价同样保留。若出现编排缺陷则停止、修复并说明受影响轮次；不得因得分不理想而替换结果。

运行前执行 `check_protocol.py`。`run_pilot.sh` 已准备，但为避免继续占用用户电脑，本轮没有启动。
