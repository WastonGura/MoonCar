# V2 全场自主探测与环境总览

2026-11-16。沿用原生 V2 场景 `survey_v2_native`，不修改地形复杂度、物理参数、默认定位或地形判定策略。取消默认的起点活动半径；仅以实际场地边界、已观测通行条件、车辆安全保护及时间预算约束运动。

自主任务 API 的 `radius` 省略或为 `null` 表示无起点半径限制。历史任务显式提供数字时保持原行为，便于复现实验。工作台不再显示半径输入，新的自然自主验证也默认不设置半径。候选位置、观察收益、任务健康检查及运动监控均支持该语义，不以另一个大圆替代旧圆。停用的主动回访流程仅适配参数，不改变原流程。

面积使用 `survey-metrics-v2`：未指定半径时累计所有实际观测到的去重投影格，不裁剪起点距离或坐标。报告同时给出总面积和相对于任务开始基线的新增面积；不以已发现面积充当覆盖率分母。场地本身仍为 30×30 m，面积包含障碍表面，不等于车辆驶过面积或可通行地面完成率。

第三张地图是独立的固定全场环境参考图：实际 V2 地形高度、地表分区、岩石/碎石、坐标与起点，可叠加两组运行轨迹及观测范围。只用于离线图示和录像，不输入定位、建图、候选选择或控制。使用实际碰撞网格恢复地形，不把低分辨率总览画成车辆已经观测的地图。

对照继续采用每组 180 仿真秒、每墙钟秒 3 帧完整录屏、1800 墙钟秒采集上限，同一起点 `(0.5,0,0)`、相同冻结源码/安装版本和资源分配。顺序运行原策略和邻域候选策略。记录真实终止原因，不强制补足时间。录像保留随车小地图及四轮面板，另提供环境总览。单轮比较只说明此次表现。
