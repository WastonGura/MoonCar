# R5 转向约束核对与未应用的接触候选

日期：2026-10-10。真实转向偏移尚未解决。本目录只做源代码、冻结模型及既有力/速度记录的只读核对，新 Gazebo 尝试数为 **0**。

## 驱动控制已验证到哪里

前一阶段 `r5-turn-control-20261010` 的四轮输入、采集和逐步记录均合格。基线左右转向最大中心偏移均约 31.31 cm；驱动载荷交替候选仍分别为 30.54 cm、30.28 cm。候选没有消除偏移，不发布。

基线四轮实际轮速对目标的最大误差约 `8.92e-11 rad/s`。当前记录没有支持“轮速命令未正确执行”。前轮横向滑动 RMS 约 `0.05456 m/s`，后轮约 `0.000005 m/s`；转动支点接近后轴 `X=-0.157 m`。前轮横向力/法向力接近 0.2，后轮约 0.185。原始力、位置、时间和资格记录的哈希见 `result-ready/audit.json`。

在**后轴持续不横向滑动**这个条件下，车体中心绕后轴运动：零线速度时转弯半径为半轴距 0.157 m，转约半圈的最大位移为 0.314 m。增加恒定前进速度会把半径变成 `sqrt(0.157²+(vx/ω)²)`，不能缩小到车体中心；只改角速度也不能改变这一几何约束。这排除了这两类简单补偿，**没有证明所有随时间变化的驱动控制均不可行**。

## 接触定义的差别

冻结模型质量 9.186 kg、质心 X=-6.237889 mm、轮距 0.3311 m、轮半径 0.076 m。四轮摩擦参数为 `mu=0.2, mu2=0.85`，未设置 `slip1/slip2`，按 SDF 默认值均为零。轮碰撞局部 Z 经姿态变换后为车体 -Y，与轮轴平行，未发现这里的方向定义错误。平板对应纵向摩擦 0.72，DART 配对后的有效值取较小者，不能把车轮单项 0.85 当作有效接触值。

摩擦系数限制可承受的切向力，滑移柔顺度描述受力与滑动速度之间的关系。二者是不同参数。原模型存在一个车轴接近粘住、另一个侧滑的实际观测；这与上述约束相符，但不足以证明 DART 软件错误，也不证明真实车辆具有相同支点行为。

源代码依据：

- [Gazebo 8.15.0 WheelSlip](https://raw.githubusercontent.com/gazebosim/gz-sim/gz-sim8_8.15.0/src/systems/wheel_slip/WheelSlip.cc)：以实际轮速和固定法向载荷估计计算动态柔顺度。
- [DART 6.13.2 接触约束](https://raw.githubusercontent.com/dartsim/dart/v6.13.2/dart/constraint/ContactConstraint.cpp)：切向约束包含摩擦限制及柔顺度。
- [SDF 14.9.0 surface 定义](https://raw.githubusercontent.com/gazebosim/sdformat/sdformat14_14.9.0/sdf/1.10/surface.sdf)：`slip1/slip2` 默认零，单位为 m/s/N。
- 本地固定 gz-physics 7.8.0 源码归档 `r5-stability-20261006/gz-physics7_7.8.0.tar.gz`，SHA256 `0d95b1dd3ea8c6f558535efe5fab6ecf5af947902a4367982e6fabd586752266`；实际 ShapeFeatures 含 Primary/Secondary SlipCompliance 入口。原 DART 修复仅涉及网格摩擦导入，本轮未修改该库。

上述 Gazebo 版本源码用于提案分析，不把 ROS vendor 包版本号当作内部 Gazebo 版本。新实验前仍须核验实际安装版本、插件加载及每步柔顺度生效，不能以源码存在代替运行验证。当前 Docker daemon 不可连接，本轮没有新增运行时验证。

## 可审查但尚未应用的候选

补丁：`result-ready/UNAPPLIED-wheel-slip.patch`。工具只在内存中添加系统并输出差异，**没有写出或应用修改后的 SDF**。

只增加原生 WheelSlip：四轮侧向无量纲柔顺度固定 **10**、纵向 **0**，轮半径仍为 0.076 m；每只前轮法向载荷估计 3.572514674 N、后轮 3.868145326 N，来自当前模型总质量、质心、轴距和月球重力计算，不读取 Gazebo 真值用于控制。该数值是单个工程诊断候选，没有实车标定依据，不扫描参数。

动态侧向柔顺度为 `abs(轮周向速度)/固定法向载荷 * 10`，轮速为零时趋于零。它保留原摩擦系数、质量、惯量、尺寸和关节定义，但**改变轮地接触的物理表达**，因此超出用户当前“保留物理参数，先修驱动控制”的授权。必须取得仅限独立测试副本的授权后才能运行，不发布正式模型或默认库。

在平地、相同绝对轮速、线性滑移未饱和、其他侧向力可忽略的假设下，解析预测支点靠近质心 X，转半圈中心最大位移约 **1.2476 cm**；名义切向力/法向力约 0.09484，小于侧向摩擦上限 0.2。**这是预测，不是测量；仍非零，也没有达到前一阶段 1 cm 的研究筛选条件。** 不据此宣布偏移修复或修改门槛。

若获授权，先冻结单项差异、有效柔顺度与力/速度关系的核验方法，再以原命令链路、D=0、1 ms、5/20/3 秒流程，在独立环境做原配置、候选和恢复对照。静置/直行副作用、全程最大偏移、转角损失、停车及采集完整性分别登记。若只降低偏移或运行时未生效，保留未通过结论；复杂场景及正式发布另行验收。

## 检查及当前结论

静态专项回归 **7/7 通过**，覆盖载荷守恒、非法几何/载荷、后轴粘住时的半径、零轮速动态柔顺度、提案不修改模型及既有插件、拒绝覆盖既有 WheelSlip、冻结实际模型核对。初次工具失败日志保留，修改的是只读分析程序，没有重写旧实验结果。

本轮未启动 Gazebo、未改模型或物理库，保留既有 419 项文件的哈希核对。完整软件/前端/固件回归在前一阶段通过；本轮只增加静态分析入口，未将前次检查当作本次运行时验收。

结论：轮速执行错误未获证据支持；后轴近似粘住可以解释当前 31 cm 轨迹；驱动交替候选失败；侧向滑移候选尚未授权、尚未测试。目标继续保持未完成。
