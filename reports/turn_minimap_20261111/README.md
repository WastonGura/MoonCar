[观看完整视频](v2-uphill-turn-minimap.mp4)，51.25 秒，1280×1072，H.264，20 fps。

本轮重跑之前的位置反馈转向原型，计划依次前进至 X=1、2.5、4 m，左转 90°，回正，再前进至 X=4.3 m。实际完成前三段行驶，在首次转向时因预测足迹触及地图障碍或安全余量而停车。回正与续行没有执行。

左上角小地图随定位位置平移，北向固定，车头箭头随定位航向变化。暗灰表示未知，绿色为已知零代价格，褐色为附加代价，橙色为安全余量，红色为禁行。青色线为定位轨迹，圆环为当前目标。人工禁行先验也包含在导航底图中。视频只选用当前录屏时刻已经收到的地图。

主画面来自 Gazebo 实际屏幕截图，按车体记录进行随车裁切放大。前进按 1 倍仿真时间播放，转向与紧邻的停车过程按 0.25 倍播放，末尾停帧 2 秒。截图墙钟通过工作台采样时钟映射到仿真时间，适合定性分析动作，接触事件的对齐精度受采样间隔影响。

底部四轮数据使用保留的关节姿态与车体记录计算。轮速和累计转角描述车轮滚动，横移沿轮轴方向计算，悬架数据相对转向起点。缺测位置显示破折号。轮速符号在正常前进时为正。

本轮共创建两个实验。首轮 experiment-d0fa4fb37388 完成第一段前进后，定位恢复等待超时。首轮录屏在 GUI 关闭时出现 X 连接退出错误，已保留原录像和日志。随后修复录屏收尾顺序，将截图频率从 6 降至 3 帧/墙钟秒，再执行本视频对应的实验。两个实跑提交之间的源码变更涉及录制工具。第二轮录屏、编码和后端均以 0 退出。录制频率与场景 GUI 会影响计算负载，本轮没有进行性能开关对照。
