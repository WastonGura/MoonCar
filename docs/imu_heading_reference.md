# IMU 朝向参考约定

`laser_odometry_node.py` 的 direct 后端输出起点对齐的 `odom` 朝向，必须明确 IMU 朝向的参考坐标系。

| `imu_heading_reference` | 初始朝向处理 | 适用入口 |
| --- | --- | --- |
| `world`（底层默认） | 扣除显式 `heading_origin` 世界朝向 | 已标定为世界参考的 IMU；独立节点须按实际传感器设置 |
| `startup` | 从首个有效 IMU 样本测量车体 yaw 零点，后续使用相对变化 | 当前 Gazebo direct 启动入口显式选择 |

IMU 安装姿态先转换到车体坐标系，再确定 yaw 零点。无效姿态、无效角速度和重复时间戳不能确定或更新零点；暂时丢帧也不会重新标定。此处理不更改原始 IMU 的 roll/pitch，也不使用真值、场景几何或 SLAM 修正。车辆仍须静止完成原有初始化与连续三次真实匹配后才能移动。

当前 Gazebo IMU 的初始 yaw 已相对于创建时姿态为零。若再扣除世界起始朝向，非零朝向启动会产生错误坐标轴；此次修复将仿真 direct 入口明确设为 `startup`。旧激光到 EKF 候选和底层 `world` 合同保留。实车须根据实际 IMU 的参考、安装和初始地图朝向选择模式，不能假定与模拟器相同。

质量状态附带 `imu_heading_reference` 和测得的 `imu_heading_offset`，便于核查运行时约定。真实 ROS 回归使用实际 IMU 回调和扫描匹配管线，覆盖 +90°、−90°、0.7 弧度启动以及安装变换、无效首帧、角度越界和重复时间戳；现场表现由后续独立 Gazebo 试验验证。
