# 2026-10-12 R5 动态转向补偿候选

用户要求修正转向偏移中的补偿设定问题。本轮撤下未发布模板中的固定前后轴倍率，新增激光/IMU 独立运动反馈、带时间与序号校验的动态执行器、过期/无效反馈停止转向及发布门禁。轮式里程计和 Gazebo 真值未进入控制器；真值只用于事后验收。旧固定分配器保留历史回放，新运行库不再接受其 manifest。

没有将新算法直接接上车辆：先在弯道做影子观察。两次新尝试中，一次世界资源路径启动失败；通过真实包索引与源码资源哈希修正后，以新目录、新签名成功执行一轮 5/20/3 秒左转。两轮失败均保留，没有恢复旧矩阵或补数。

200 个运动反馈中仅 131 个控制器判为可靠。69 个因配准、可观测性及反馈门槛被拒绝；事后真值还发现控制器判为有效的增量最大误差 35.928 mm。完整轨迹核对因 12.1 秒配准无效而停止。**反馈未通过，动态执行 0 轮，非平面偏移未修复**。该轮旧固定配置的真实位移仍为 171.735301 mm，输入、图像采集和排空合格。

动态算法的增益、±5% 分配范围及实际效果尚未通过运动验证，不能作为生产补偿。`turn_defaults.json` 仍为 `legacy`，`turn_release.json` 仍为 `approved:false`。真实旧模型/R5 的 legacy 展开保持一致；候选物理与传感器定义除已声明 D=0 和控制系统扩展外保持一致。

完整软件回归 540 项（535 通过、5 既有跳过）；前端 3 项、5 个 JS/MJS 语法、固件严格编译/UBSan、237 个脚本/ROS Python AST 通过。新反馈/回调/轨迹核对 18 项和 C++ 有效期解析专项通过。停止后仅更新说明文档并重新生成与源码一致的最终包，没有伪称获得物理执行通过。

原始失败、每步数据、传感器、控制器决策、配准误差、源码与库哈希、安装核验及性能记录归档到独立证据目录；只关闭本轮容器，不提交或覆盖其他旧改动。

详细结果见 [动态补偿报告](../../reports/R5_ADAPTIVE_TURN_20261012.md)。下一步先解决独立侧向位移反馈的可靠性，再验证动态执行，不能继续把固定平面补偿推广到弯道非平面区域。
