# 原 v2 约 10.286 mm 转向偏移：独立复核

2026-10-11。只读分析原始物理步和接触记录，未启动仿真、未改车辆或原证据。

结论：支持“轮地接触与载荷发生突变，水平合力不再平衡，推动真实车体中心移动”这一直接机制。尚不能确认接缝触发异常的具体原因，不能排除接触计算产生的数值异常。Gemini 的“完整根因已确认”表述过强。

本轮对象是采用滑移与驱动分配测试候选后剩余的约 1 cm 偏移，不是原模型约 31 cm 偏移的全部根因。

## 从原始记录确认的事实

- 运动窗口为迭代 5201–25200；原 v2 轮最大中心位移 10.285963 mm，平板对照为 0.172556 mm。
- 迭代 17019，左前轮出现第三个接触点。其中接缝点满足 `y-x=0.25004 m`，深度记录为 0，法向带水平分量；这个点承担左前轮全部约 8.469 N 垂直载荷。此步水平合力已经突变。其他两个接触点有约 1.123 nm 深度，却记录为零力。
- 17020，左前、左后接触快照为空。17021，左前载荷升至 12.941 N，最大记录深度为 2.507 μm。
- 右前轮连续空接触记录实际为 17022–17262，共 241 步。右前与左前同属前轴，不能称作对角轮。空快照与轮心高度支持接触丢失线索，但不替代完整接触几何核验。
- 因而异常链不能简单从“17020 失触”开始：前一步额外接缝接触及受力突变已经出现。应检查这个额外接触如何改变约束和载荷分配。

## 力与运动是否对应

沿用 Gemini 的 17020–17519 积分，水平冲量为 `(-0.047086,-0.094426) N·s`。按总质量 9.186 kg 预测速度增量 `(-5.125851,-10.279290) mm/s`。

用整车质心世界位置作中心差分，17020 到 17520 的速度增量为 `(-4.924013,-10.456851) mm/s`，向量相对差约 2.33%。合力方向和运动变化相符，支持受力失衡解释。把积分窗口平移一物理步时差为约 1.26%；记录的是离散接触快照和差分速度，不能据此宣称精确动量闭合。这里展示两种边界对齐，不以较小误差择优宣布通过。

总质量乘以底盘几何中心速度不能直接替代整车动量；底盘原点和整车质心不同。平板对照尤其明显：中心基本停留，但偏心质心仍随转动运动。

Gemini 文本中的方向角有计算错误：上述冲量方向为 −116.504°，底盘速度增量方向为 −115.707°；最终位移方向 −125.034°是另一个量。其 5.14% 实为 Y 分量误差，速度大小误差约 4.49%。

平板对应窗口的水平合力 RMS 约 0.001870 N，并非严格为零；启动及完整运动窗口最大约 0.118252 N。其四轮始终各两个接触点、无空接触、法向垂直的差异得到原记录支持。

另一个报告错误：17020 当步位移约 0.345 mm，不是此前全过程最大值；此前最大约 0.606810 mm，发生于 9984 步。不能把 17020 定义为全程第一次移动。

## 下一项因果对照的准备问题

Gemini 拟将出生位置平移 `(+0.05,+0.05) m`，理由是避开 `y-x=0.25` 接缝。但平移后 `y'-x'=y-x`，它沿该接缝平行移动，对这条直线的垂直距离不变。因此该参数没有证明能避开所指接缝。

有限线段、相邻网格和其他接缝的接触会随平移改变；这并不等于整个试验无意义，但必须重算实际轮面轨迹与网格接缝相交的位置和时刻，再提出可区分的预测。不能直接保证事件消失，也不能仅凭偏移下降判定根因。

先让 Gemini 完成所附离线反馈，再确定一项可验证的接缝相位对照及恢复对照。未启动新实验，Gemini 提议的两轮预算不是新的用户授权。
