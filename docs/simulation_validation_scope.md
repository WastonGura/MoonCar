# MoonCar 仿真用途与精度要求

## 2026-11-02：用户明确以实际可用为开发目标

优先完成能使用的地形勘测流程，不继续以性能完美为目标。100ms逐帧延迟、每次优化至少改善5%、完全零迟到等此前实验指标继续保留记录，但不再作为进入V2功能验证或判定项目可用的独立硬门槛。历史实验按原协议保留原结论，不重写成通过。下文的精度建议仍是暂定工程预算，不自动升格为用户批准的要求。

当前重点是：车辆能完成观察位置间的移动、转向和地形采集；短暂定位失效时安全停车，恢复就绪后能在有效许可下继续任务；结束后能交付地图、覆盖和误差记录。迟到和小幅性能波动按它是否造成任务停滞、错误导航或采集不可用来判断。频繁打断、无法恢复、控制或地图明显错误属于需要修复的问题。

下一阶段保留已验证结果等价的优化，停止为几个百分点反复微调，直接做V2任务闭环验证。把“安全停车”与“整轮实验立刻销毁”分开：当前驱动遇到一次健康下降就退出，无法验证恢复后能否继续。后续验证需记录暂停、恢复和续执行，不以删除失效记录、忽略真实停车或强行发运动命令代替恢复能力。运行中的健康检查与运动许可先保留；如需调整参数，应由任务表现和观测证据支持，不单靠追求较漂亮的统计。

本次优先级调整不代表新旁路定位已替换默认，也不代表此前未完成的长跑已经通过。

更新日期：2026年10月19日。模型优化已暂停，保留现有基线，冻结分段积分研究候选。本文确定后续验证的用途和优先级；精度目标用于任务设计，没有修改运行配置或宣称已经达标。

MoonCar 的主目标已由用户明确为地形勘测：在指定区域内采集可复核的地形信息，报告采到了多少、几何误差多大，以及哪里仍然未知或不确定。导航与避障负责让车辆安全到达观察位置，车辆物理模型负责提供适用范围明确的运动与观测条件。项目还比较不同探测策略在相同预算下的勘测成果，并准备后续硬件迁移。

当前勘测成果以有观测支持的地表高度和坡度为主，保留原始点云、采集轨迹与时间。覆盖范围、几何误差、缺测／无效区域和时间成本应一起交付；障碍及坑边表达能力按实际验证范围说明。仅有车辆到点、漂亮点云或较高采样充分度，均不足以说明勘测完成。现有5 cm高度、5°坡度等仍为待任务确认的暂定目标；本次用途确认没有自动批准这些数值为正式要求。

不依赖硬件的软件缺口、已有能力和开发顺序见[地形勘测软件缺口与开发优先级](terrain_survey_software_backlog.md)。

## 当前需要回答的问题

1. 深度观测能否生成位置、高度和坡度可信的地表地图？地图中哪些地方没有观测、无法表达或误差过大？
2. 车辆能否根据勘测需要到达观察位置，避开障碍与禁行区，并在数据失效或任务结束时停车？
3. 在相同场景、起点、时间和设备条件下，哪种探测策略采到了更多达标地表？差异能否在重复和条件变化后保留？
4. ROS 接口、坐标、时间、控制与记录流程，哪些可以进入硬件联调，哪些仍依赖仿真假设？

[项目说明](../README.md)、[需求](requirements.md)和[软件仿真收尾目标](simulation_closeout.md)支持上述用途。当前成果包含二维定位、传感器点云累计和单层地表拟合；单层地表不能完整表示垂直岩壁、多层结构，也没有自动证明实车爬坡极限、松土通过性或真实月面性能。

原需求和早期精度分析中的传感器、车型及精度估计存在历史版本。当前实现与硬件缺口以实际代码、运行配置及[车辆传感器缺口](hardware_parameter_gaps.md)为依据。

## 各项用途需要的精度

下表区分当前实现和后续任务目标。新增目标属于工程建议；已有地表验收值仍是暂定仿真目标。它们没有被写入控制器或用于重判旧结果。

| 用途 | 当前实现 | 后续验收关注什么 | 精度与判定尺度 |
| --- | --- | --- | --- |
| 粗地表测绘 | 25 cm地表格、5 cm体素；地表评分有固定参考及区域 | 截止时刻的覆盖、几何准确性、无效区域和分地形误差 | 每格高度误差≤5 cm、坡度误差≤5°，已重建部分达标率P≥90%为暂定精度目标；覆盖仅统计，无通过门槛。分列平地和非平地，未测类别精度未知 |
| 探测策略比较 | 就近、覆盖、地表补采等版本共用导航与采集；按仿真时间预算执行 | 相同预算内达标地表面积及失败成本，而非某个策略必须获胜 | 使用固定区域、参考、阈值和版本的S(T)=100×达标面积/评价面积；同时列C、P、高程RMSE、坡度MAE、路程、耗时和故障。没有依据指定“必须提高多少百分比” |
| 导航到观察位置 | 工作台位置到达容差为25 cm，不要求终点朝向；在线全局地图10 cm，局部代价地图5 cm | 同时核对估计到达与独立真值到达、轨迹偏差、净空、碰撞和耗时 | 初步以真实终点距离不超过25 cm设计低速宽通道任务；观测朝向另核验，不能由位置成功推断。定位水平误差P95≤5 cm可作为预算起点，仍需与净空合算 |
| 地形避险与路径选择 | 地形分析格30 cm、通行代价格20 cm；轻度坡度5°、禁行坡度18°等为设计阈值 | 危险区域是否被误判可通行；风险是否在全局和局部地图保留；车辆实际包络是否进入危险区 | 每个有可信检测记录的冻结场景要求零碰撞、零禁入。临界坡度／台阶／落差要单独验证；粗测绘的5°误差不能直接认证18°附近安全 |
| 软件链路与停车 | ROS、TF、传感器、Nav2、工作台及运动许可联动 | 指令与反馈一致；故障可识别、记录、停车；数据和清理完整 | 接口、单位、时间来源等属于正确性要求。每个预声明故障用例按预期处理，不能用平均成功率掩盖一次停止失效 |
| 真实牵引与坡面动力学预测 | 摩擦、侧滑、载荷与部分几何尚未实测标定 | 若未来要预测实车坡度极限、打滑量、牵引力或功率，需要相应实测对照 | 当前用途尚不足以制定通用的“受力误差必须1%”生产要求。待明确要预测的物理量及可接受误差后另立标定任务 |

定位P95的5 cm建议取在线全局10 cm格长的一半作为初步误差预算，属于设计选择，不能从格长推出实际定位能力。P95不能代表最坏误差或安全保证。安全边界还要考虑最大误差、地图误差、车辆包络、延迟和制动距离。真值用于离线核验，不进入在线导航或策略决策；仅在启动时确定固定坐标关系，不用最终轨迹反向配准消除被测漂移。

地图分辨率表示格子大小。5 cm体素、5 cm栅格和“高度误差不超过5 cm”是三个不同概念。C、P、S及缺失数据处理沿用[地形采集评价v1.2](mapping_acceptance.md)；C和S只作统计，P检查已测部分的几何精度，采样充分度Q也不能替代几何准确性。

目标障碍的最小尺寸还没有成为统一的正式要求。早期文档提到15至20 cm障碍，但当前多层网格及视线条件不能自动保证检出；窄坑、低矮石块和边缘应另设场景，先核查是否可观测，再讨论通行。

## 精度如何影响结论

### 相机与姿态的误差会直接进入地图

三米外的点，姿态偏差1°对应约5.2 cm的位置偏差；如果误差来自俯仰，可能直接消耗整个5 cm高程预算。相机安装位置、云台关节、IMU、车体倾斜和图像时间必须对应起来。二维定位本身不会自动提供坡面上的正确相机高度。

对小误差，可用下面的一阶量级关系检查预算。角度以弧度表示：

`点位置误差量级 ≲ 位姿平移误差 + R×姿态误差 + (v+R×|ω|)×时间差 + 深度误差`

这是分项量级估计，忽略其他结构误差；它不能代替逐帧投影核验，也不能把未知误差未经证明就按独立高斯噪声合并。以R=3 m、v=0.16 m/s、ω=0.2 rad/s为例，20 ms时间错配约贡献1.5 cm，100 ms约7.6 cm。例子解释了为什么“话题仍在更新”不足以证明数据足够同步；实际允许时间差应按当轮速度、距离和剩余误差预算确定。

因此，目前不宜把深度、定位和姿态的容差分别都设成5 cm后，声称总误差仍是5 cm。后续先从同步记录拆出各项贡献；如果5 cm整体目标达不到，应记录实际能力并限制用途。

### 粗测绘合格不能直接推出临界地形安全

当前程序把18°作为禁行坡度。假设某格估计16°，坡度误差只保证在±5°，真实值可能达到21°，因此不能确认可通行。临界区域应进入不确定或保守处理；要辨别相差2°的坡面，坡度误差必须显著小于2°，或扩大决策间隔。

18 cm台阶、12 cm落差和4 cm粗糙度等同样是现有设计阈值，尚非R5实车能力证书。本次没有改阈值；后续需区分“传感器看见几何危险”与“车辆力学上能通过”。人工禁行区是操作员先验，不能据此声称相机已经识别松土材料。

### 侧滑通过轨迹影响任务

冻结研究中，候选平地约1.59 mm中心偏置形成约3.2 mm参考点圆周偏移，稳定段未显示明显持续漂移。对当前25 cm到点任务，这一项通常不会主导误差。1 mm中心门槛属于上一轮模型研究标准，不能直接拿来判定整个导航项目失败。

坡面则不同：新工况最大参考点偏移约0.15至0.60 m，可能改变实际净空、到达位置、观测视角和动作耗时。其中心／匀速漂移分解不可判定，应直接记录完整轨迹与任务结果，不能把无效拟合系数当成实测漂移。原地转向开环偏移也不等于闭环Nav2的最终到点误差。

这决定了侧滑参数的当前用途：检验导航和采集在存在滑移时是否仍可靠。只有当某项任务结论确实依赖准确预测滑移，才需要继续开展对应模型标定。

## 真正影响结论的参数

以下优先级来自代码依赖关系和已有故障证据，没有进行新的参数扰动试验；尚不能给出每个参数对成果贡献的百分比。

| 优先级与参数 | 怎样改变结论 | 当前发现与处理方向 |
| --- | --- | --- |
| 优先核查：坐标、时间、相机内外参、IMU与云台姿态 | 点投错位置／高度，改变坡度、覆盖和达标面积；传感器失效还影响停车 | 读取真实CameraInfo与时间戳对应TF；核查map/world、相机高度和倾斜。厂家外壳尺寸不能代替安装标定；新鲜度超时门槛不能当作投影时间误差上限 |
| 优先核查：车辆碰撞包络、Nav2 footprint、膨胀与候选净空 | 决定窄路可达、避障距离和观察位置集合，从而影响策略成绩 | 基础导航仍使用0.86×0.72 m的统一footprint和0.65 m膨胀半径；当前地形入口未随R5切换重设footprint。需与展开后的实际包络、转动扫掠及安全余量对照，暂不认定它必然错误或自动缩小 |
| 优先核查：风险地图叠加、未知区规则、地图更新 | 危险区可能被清成自由区，候选与控制器对可达性判断冲突 | 已有自主停滞由全局／局部禁行图不一致导致，修复风险层后限定批次10/10移动目标成功。这是已有直接证据，见[入口验证](../reports/R5_ENTRY_NAVIGATION_20261016.md) |
| 优先核查：深度采样、体素、点数与展布门槛、地表拟合、参考定义 | 改变哪些格子可拟合、误差是多少和分母多大，直接改变C/P/S | 分开记录25 cm采集格、5 cm体素、30 cm地形格与20 cm风险格；保留无效格。不能通过降低拟合门槛或挑选参考提高成绩 |
| 优先核查：策略视场与相机位置代理、动作时间代理 | 决定预期收益、候选排序及预算内能否完成动作 | 规划器用60°水平视场和车前0.435 m等代理；R5深度仿真声明73°视场。它们不是已证实一致的几何模型。普通动作以0.20 m/s估算移动时间，控制器期望线速度为0.16 m/s；预测残差需按实际动作核查 |
| 按任务验证：轮径、有效转向轮距、实际速度／加速度、控制与到点容差 | 改变里程计、跟踪误差、转向时间、停车和任务截止行为 | 几何轮距不自动等于滑移转向有效轮距；工作台25 cm位置容差不能代表静态配置8 cm容差。先分清实际入口和实际加载值 |
| 按场景验证：摩擦、侧滑、轮载、质量重心、悬架、重力 | 在斜坡、松散地面及转向时改变滑移、姿态、接触和可达性，也间接影响观测 | 保留基线并标明未标定范围。当地面运动误差足以改变上述任务结论时再升级验证。月球重力与地球试验不是同一工况，不能直接移植结果 |
| 按收敛验证：物理步长、接触求解与传感器交付 | 数值异常、错误加载或丢帧会伪造成模型／策略差异 | 按实际任务观察步长与交付是否改变结论；研究用0.25 ms不能自动取代生产1 ms。积分公式逼近到万分之一不意味着整车具备同等准确度 |
| 目前低优先级：积分尾部的更小误差、真实感外观细节 | 目前没有证据表明继续优化它们会改善导航或测绘结论 | 分段积分候选继续冻结。外观若影响测距或视觉算法输入，应另作观测条件变量；不把渲染粗糙度当作土壤摩擦或几何粗糙度 |

采集、规划、控制和离线评价可能各自使用不同精度；差异可以有合理用途，但必须被说明。尤其R5与旧车型切换时，应核对观察预测和导航包络是否仍适用，而不只更换外观和物理模型。

## 基线与候选的使用规则

- 默认旧入口、R5刚性默认、可选的`r5_support_v1`支撑配置和分段积分研究候选是不同配置。后续每个任务明确固定车型、支撑、控制、传感器及实际库，不把不同配置的数据混为同一基线。
- 现有默认配置继续保留；本次没有推广支撑或积分候选，没有改摩擦、侧滑、土壤、轮速分配、Nav2或安全参数。
- 10月18日研究中的台架低速离散偏差、变载失败、平地中心超标与坡面拟合无效全部保留。它们界定候选用途，不能用新任务目标重写为模型研究通过。
- 已观察工况作为开发与回归资料；未来若需要独立验证，先固定任务、范围和判定规则，再采集新条件。完成标准是形成可靠结论，失败和无优势也是有效结果。

## 后续验证的最小范围

本轮只梳理要求，没有启动以下试验。后续应按顺序补齐用途相关证据，再决定是否需要更多物理模型工作。

1. **核对实际配置。** 从运行产物对照车型、碰撞包络、footprint、相机CameraInfo／TF、云台反馈、时间戳和采样频率。先解释上表已有代理差异；不自动通过缩小安全余量、调摩擦或改评分修复结果。
2. **验证闭环任务。** 在冻结的宽通道、必须绕行障碍、禁行区与温和坡面任务中，保留完整真实轨迹、估计轨迹、到达误差、实际净空、观测质量和停车记录。传感器／定位失效单独注入并检查停止；安全边界应以包络与停止过程核验，不能只看车体中心。
3. **验收测绘并比较策略。** 在已经验证参考和坐标的任务范围内，先计算现有基线的C/P/S及高程／坡度误差，再决定策略对照。按场景和起点分组、整轮重复，保留所有失败；比较差异须同时考虑重复波动和测量／配准敏感性，不能把大量相邻格当独立样本。

若基线在用途要求内可靠，模型优化继续暂停。若结论只在某个摩擦、姿态或传感器假设下成立，就缩小结论范围并记录依赖；需要解释真实牵引、负载变化或坡面滑移时，再以目标硬件／土壤数据另立标定任务。
