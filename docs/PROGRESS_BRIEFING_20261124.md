## 三、下一阶段核心议题：实车硬件集成（H1）与团队分工

详细电气、接口与验收细则见 [hardware_handoff.md](hardware_handoff.md) 与 [hardware_pan_tilt_spec.md](hardware_pan_tilt_spec.md)。开会建议重点拍板以下 5 件事：

### 3.1 硬件清单与采购确认
1. **底盘与动力控制**：确认四轮电机额定电压/堵转电流/减速比、编码器每圈计数与电平、4 路独立电机驱动板选型、STM32 型号与原理图引脚表（避免 4 路编码器 + PWM + UART + SWD 引脚冲突）。
2. **主控与供电**：树莓派 5（推荐独立 `5V/5A` 稳压供电 + 散热）与动力电池 BMS / 保险丝 / **独立物理急停开关**（严禁仅依赖软件停机）。
3. **二轴观测云台（BOM 约 ¥317）**：推荐 2× 飞特 `STS3215` 串行总线磁编码舵机（12 位绝对编码器）+ `URT-1` 转接板 + 铝合金 U 型支架 + 独立 `12V→7.4V 5A` DCDC 供电（与树莓派电源分路、单点共地），安装高度对齐仿真 **`z ≈ 0.28 m`**，相机线预留 U 型防缠绕环。
4. **核心传感器**：深度相机（OAK-D Lite / RealSense D435i）、9 轴 IMU（确认 SI 单位与 ENU 轴向）、以及 2D 激光雷达（如 SLAMTEC S3，若保留辅助避障）。

### 3.2 真机接入与联调顺序（严格分步，不可跳步）
1. **阶段 H1-1（无电机台架 & STM32 固件）**：核对原理图与看门狗 → 移植 `firmware/stm32/core`（已通过 C11 UBSan 与虚拟串口验证）→ 车轮架空限流上电，逐轮核对编码器正负号、轮径、轮距与速度闭环 → 实测拔串口 / 停上位机 / 拍物理急停的独立断能停机。
2. **阶段 H1-2（树莓派 5 传感器 & 云台驱动）**：部署 Ubuntu 24.04 arm64 + ROS 2 Jazzy → 接入 RGB-D、IMU、云台 `/mooncar/cmd_camera_pan|tilt` 与 `/joint_states` → 完成**相机内参、RGBD-IMU 时间同步、相机-云台-车体实测外参标定**（统一 `use_sim_time:=false`，核对单一 TF 发布者，严禁直接套用仿真外参）。
3. **阶段 H1-3（只读定位与建图评估）**：手持或遥控推行实车，先在不开启自主控制的情况下验证 `rgbd_window` 定位实时帧率（树莓派 5 CPU 负载实测）、实测直线/转角/闭环误差并重新标定 R5 真机漂移系数 $(\sigma_0, \alpha_s)$；核验 `terrain_node` 在强光/暗色石块/真实坑沿下的深度缺测保护。
4. **阶段 H1-4（受控场地低速自主验证）**：在受控室内/模拟沙盘完成平地低速导航 → 人工急停与断连测试 → 自主探索 `hybrid_frontier_v4.1` 小范围实跑 → 地球重力下的斜坡测试（重新实测真机坡面安全转向阈值与滑移包络）。

### 3.3 建议的团队并行分工
- **硬件 / 嵌入式组**：底盘组装、电源与物理急停布线、STM32 板级 HAL 移植（对接 `firmware/stm32/core` 与 [uart_protocol.md](uart_protocol.md)）、云台支架与供电装配。
- **传感器 / 标定组**：树莓派 5 ROS 2 环境搭建、RGB-D / IMU / 舵机驱动接入、内参/外参/时间同步标定与实车算力基准测试。
- **算法 / 上位机联调组**：基于实车标定数据更新 URDF / `nav2_params_r5.yaml` / 实车漂移系数 $(\sigma_0, \alpha_s)$、实测网页实时遥测与自主探索参数微调。
