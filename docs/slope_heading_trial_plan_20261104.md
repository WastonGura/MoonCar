# 坡面原地转向的限定尝试与替代方案验证

用户目标：先尝试实现可用的坡面原地转向；若不能，再设计满足改变方向和继续探测需要的方法。本轮不修改轮胎、摩擦、重力、悬架、定位算法或回访，不恢复历史1cm硬门，也不声称一个候选能证明所有控制方法不可能。

固定R5/independent_linear_v1/.25ms/rgbd_window，原V2坡面、同一初始位置和前3段上坡动作。已有f62ba61报告中两次90°纯转净位移.322/.302m、线速度指令0作为背景基线；不冒充同批重复对照。

## 阶段A：仅一次半速纯转候选

采用私有导航包副本，在节点启动前仅将`max_rotational_vel`从.3改为.15rad/s；最小转速.075、角加速度.4及其他配置保持原值。运行前3次上坡、90°、转回以及每段后2仿真秒等待，记录完整真值、命令、定位和采集。实际命令峰值须证明限速被消费；默认安装包保持原SHA，不用运行时参数值冒充插件已更新。

判定以能否近似保持原位置、完成朝向和稳定观察为目的，报告净位移、最大偏移与停留期运动，不要求数学零位移。若总偏移仍与原先同量级或观察停留继续明显滑移，不继续扫速度，转向阶段B。侧滑实现中柔顺量随轮速变化，减速不会自动意味着总位移减半，这是本候选要验证的机制线索，并非已证明的唯一因果。

## 阶段B：用已有云台满足观察朝向

若A未形成可靠原地能力，运行同样的前3段上坡；保持车头沿坡向，用现有受保护云台接口转向左侧pan90°、回到pan0°（tilt沿用-15°观察姿态），再按正常导航前进到x4.3m。检查车体参考点漂移、云台实际反馈、新观测及续行；该终点只验证最小动作衔接，不替代跨越此前x4.55附近视觉失效位置或整坡下行。

这只能替代“为了观察而旋转车体”。若任务需要真正改变行驶方向，替代设计应在已观测地形中选择能够沿当前方向抵达的平缓位置后再转向；没有这样的通路时才评估带初始朝向约束的缓弯路径。不能让路径跟随器在到平地之前又自动执行坡面原地旋转，也不能用一个终点无碰撞代替整个扫掠包络检查。无安全可行路径则明确停止，不强行转向。

## 记录与边界

两个阶段最多各一个新世界，采集异常原样保留。开始前提交验证代码、冻结源和安装收据。修正测试侧预算状态判定，生命周期快照I/O错误记账且不打开就绪门，其他异常保存完整堆栈；不由测试侧强行放宽产品定位或运动许可。结果报告同时保留已知独立视觉特征问题及未覆盖的方向/坡度，不直接替换工作台默认方案。
