# 地形采集评价 v1.2（覆盖仅作统计）

2026-10-19调整：按用户要求，移除总体及分地形的有效覆盖率审核，也取消由覆盖门槛推导的S≥72分要求。C_obs、C、S及缺测／拟合失败仍如实统计；它们不参与通过判定。当前评分器为`mapping-acceptance-v1.2`，车辆、物理、控制与重建基线保持。历史v1/v1.1协议和结果不改写，使用新规则复算时另存并标明规则变更。

初版日期：2026-09-14。状态：已实现离线评价器，并用公式算例、异常输入和真实同步深度记录核验。精度阈值仍为暂定仿真目标，不代表项目或实物已经通过验收。

本标准回答：在预先规定的时间和区域内，小车采到了多少具有规定几何精度的地表？它适用于当前单层地表表示，不是完整三维重建、可通行性或实物硬件验收标准。

## 1. 先固定任务，再计算分数

每次试验开始前保存：场景文件及哈希、起点和朝向、评价区域、评价网格、参考表面及分类、允许排除的格子及原因、时间预算、精度阈值、算法版本。不能看到结果后修改分母、删掉困难地形或放宽误差阈值。

- 使用现有 0.25 m 地表网格，每格面积 0.0625 m²；在线导航当前使用 0.10 m 栅格，旧静态配置曾使用 0.05 m，两者不能混淆。
- 评价区域由任务协议给定，可以是矩形、圆形或多边形。按固定参考坐标中的格心判断归属。
- 主评价集合 Ω 是该区域内、在任务开始前被参考数据确认为可表达为单层地表的格子，面积为 AΩ。坡面不能因为车辆不准备驶上去而排除；探测任务不等于要求驶过每个地表格。
- 岩石侧面、垂直面、多层结构、混合边缘等不适合当前表示的部分必须单列面积及原因。必须报告 AΩ/任务区域面积，不能把 Ω 上的成绩称为整张三维地图的完成率。
- 参考无法建立的区域不能事后静默排除。若该区域属于原先约定的 Ω，整轮综合分标为“不可评价”，先解决参考问题。
- Ω 不因算法发现多少区域而扩大或缩小，不因拟合失败而删格。未探测、被遮挡但属于 Ω 的格子仍保留在分母。
- 时间预算 T 按地图及任务预先固定，所有策略一致。旧实验的 90 秒只是历史预算，不自动成为所有地图的达标期限。

## 2. 每格怎样算合格

对 Ω 中每个格子 i 定义：

- Iᵢ=1：在评价截止时刻前，具有真实传感器观测支持，并输出可评价的地表高度和坡度；否则 Iᵢ=0。
- 现有格式可从有效地表输出开始适配，但各策略必须共用同一输出有效性判定。当前最低支撑为至少 6 个体素点和满足 XY 展布的平面拟合；不能给某个策略另设更宽的规则。
- ẑᵢ、θ̂ᵢ：输出地表在格心的高度和坡度大小；z*ᵢ、θ*ᵢ：相同位置、相同目标表面定义下的参考值。
- e_z,i=|ẑᵢ−z*ᵢ|；e_θ,i=|θ̂ᵢ−θ*ᵢ|，坡度差单位为度。
- Gᵢ=1 当且仅当 Iᵢ=1、e_z,i≤ε_z 且 e_θ,i≤ε_θ；其余 Gᵢ=0。

这里比较坡度大小，尚不包含坡向、完整法向或粗糙度准确性，不将高度/坡度联合达标说成所有地形属性均准确。后续若扩大目标，必须升级指标版本。

有数据但误差过大的格子算“不合格”，不能从精度分母删除。算法输出的错误表面也不能通过事后挑选更接近它的参考表面变成合格。仅凭插值、模型预测或场景真值填出的未观测格子不算实际采集成果。

## 3. 覆盖率、精度与综合分

设 aᵢ 是每格面积；等面积网格可直接用格子数量代替面积。

| 符号 | 公式 | 含义 |
| --- | --- | --- |
| A_obs | 收到传感器有效点的格子面积之和 | 原始观测面积，可含尚不能拟合的格子 |
| A_est | Σᵢ∈Ω aᵢIᵢ | 已产生可评价地表估计的面积 |
| A_good | Σᵢ∈Ω aᵢGᵢ | 高度和坡度同时达标的采集面积 |
| C_obs | A_obs/AΩ | 原始观测覆盖率，分子也仅限 Ω |
| C | A_est/AΩ | 有效重建覆盖率；参与主分数的覆盖项 |
| P | A_good/A_est | 已重建部分的几何达标率；不是分类器的 accuracy，也不是恢复概率 |
| S | 100×A_good/AΩ = 100×C×P | 达标地表覆盖分，0～100 分，越高越好 |

公式中的 C、P 用 0～1 的小数。例如 C=0.8、P=0.9，则 S=72 分，不把百分数 80 和 90 直接代入。

S 的含义是“规定评价地表中，已有多少比例被采集且达到几何要求”。它不是若干指标随意加权后的抽象分，也不是独立的测量准确率。它仍不能替代分项指标和安全底线。

边界情况：

- AΩ=0、参考未验证、坐标对应无法核验、原始记录缺失：S=null，验收状态为“不可评价”，不能填 0 分冒充有效样本。

`mapping-acceptance-v1.1` 保留 v1 的公式、阈值和固定分母原则。参考地表仍在查看采集结果前用 17×17 与 33×33 采样核验；若某格高度或坡度拟合未达到既有收敛限值，该格预先归为 `edge_or_complex` 并从可评价面积中排除，同时记录 `excluded_unstable_cells`。缺少参考或可评价掩膜不一致仍会令整次评价不可评价。
- 任务与参考有效，但实际未采到可评价地表：C=0、P=null、S=0。此时通过 A_good/AΩ 定义 S，不计算 0×null。
- 格子具有完整参考但本轮没有观测：Iᵢ=Gᵢ=0，计入 Ω，贡献 0 分。
- 若记录充分但触发导航/安全故障，仍保存 S 和已有成果，验收状态记“未通过”；故障不得从试验总表删除。

必须并列报告高度 RMSE 和坡度 MAE，统计集合为全部 Iᵢ=1 的格子，不只计算合格格子：

RMSE_z = sqrt[Σ aᵢIᵢ(ẑᵢ−z*ᵢ)² / A_est]

MAE_θ = Σ aᵢIᵢ|θ̂ᵢ−θ*ᵢ| / A_est

A_est=0 时上述误差为 null。另保留高度绝对误差 P95，以免平均值掩盖局部大误差。

## 4. 首版待确认的阈值

这些数字是提出供团队讨论的科研仿真目标，不是外部标准、传感器厂家承诺、实物实测能力或已经通过的指标。现有项目需求没有给出足以确定地形精度门槛的使用要求。

| 参数 | 建议首版值 | 性质 |
| --- | --- | --- |
| 高度容差 ε_z | 0.05 m（5 cm） | 暂定目标；不是从体素尺寸直接推导出的准确度 |
| 坡度容差 ε_θ | 5° | 暂定目标，须与任务需要区分的坡度差确认 |
| 有效重建覆盖率 C | 无门槛 | 描述已重建面积，不参与通过判定 |
| 几何达标率 P | 至少 90% | 暂定精度底线 |
| 达标地表覆盖分 S | 无门槛 | 描述合格面积占比，不参与通过判定 |

精度检查要求：评价有效、在冻结的 T 内取得至少一份有效地表估计、已测部分P≥90%。运行故障和已记录安全失败仍判未通过；未认证安全时保持“几何指标达标，安全尚未认证”。该结论仅适用于有效估计的部分，未测区域精度未知，不声称整个任务已完成。安全事件的检测与日志也必须具备核验依据；没有检测记录不等于已证明零碰撞。

S不决定通过与否。例如C=90%、P=80%得到72分，但精度不达标；C=20%、P=100%得到20分，已测部分可通过精度检查。

分别报告平地和非平地的C、P、S；有有效估计的类别分别检查P，不能用大量准确平地掩盖坡面的测量误差。没有有效估计的类别明确列为未评价、P=null，不作为隐含的覆盖失败条件，也不声称该类别精度已通过。分类来自事前参考，不按算法结果分组。复杂/表示范围外区域另列。

新任务不设置`minimum_coverage`。旧任务与冻结参考中的该字段保留兼容，当前评分器忽略其门槛作用；返回的生效profile不再包含它，且明确标记`coverage_gate_enabled=false`。未采到任何有效地表时P仍为空、精度检查不能通过。缺少可靠参考时继续标为不可评价。

确认阈值应根据“需要分辨多小的高度变化、区分多大的坡度差、允许多大地图误差”进行，再冻结用于验证。任何修改产生新版本，不能因某个算法未达标而只给它换阈值；旧数据不成为修改后方法的独立验证集。

## 5. 同预算比较与继续采集

- 每次从空白档案启动，各策略共用场景、起点、传感器、参考、Ω、T 与阈值；保留首次评价基线 S₀。
- 主结果是截止 T 时的 S(T)，同时报告 S₀ 和 ΔS=S(T)−S₀。初始条件差异必须显示，不能把已有成果计为本轮新增。
- 提前结束的策略保持其最终地图至 T，不重新采集，不把它的耗时缩短后另算更有利的面积/秒来替换主要指标。提前故障仍记故障。
- 地图只能使用时间戳≤T 的观测；后台报告晚生成不会延长采集预算。缺少完整截止前数据则标记证据缺口。
- 不同预算分开比较；原始路程、转向、耗时、失败数作为成本与诊断，不先引入一组未经需求确定的权重。
- 两种策略 S 相同可能有不同 C、P；报告完整分项。单次结果不证明稳定优势，多地图结果按地图分别列出，不只给一个总均值。

## 6. 参考、定位与机器学习的边界

参考应来自冻结场景的真实目标表面或独立测量，并与输出使用一致的格心高度/坡度定义。现有最高视觉表面诊断不能不经审计就当作任意相机可见面的真值；5×5 采样对细小结构的漏检也必须检查。

必须核验固定 map/world 变换、单位、表面定义和时间对应。被测定位漂移属于地图误差，不能用最终采集地图反向配准后再把误差说成原始系统精度。也不能只保留定位表现好的时段来完成对齐“验收”。

上述参考只进入离线评价和训练标签，不进入在线候选评分、采集地图或前端“已采集”内容。若采用机器学习，可以学习预测 ΔA_good 等结果；在线输入必须来自当时真实观测，不能读取真实 A_good、未来帧或世界几何。具体学习方法尚未在本标准中确定。

## 7. 旧实验如何解释、还缺什么

此前的三策略对照按“有效拟合面积净增”比较，公式是 A_fit,end−A_fit,start。它可以评价当前规则产出了多少可拟合地表，但没有与可靠参考逐格验算，因此不能代替本标准的 A_good、P 或 S。

最近六轮没有经过统一参考验收的高度/坡度误差结果，不能现在填一个“准确率”或综合分，也不能把之前约 100 m² 的有效拟合净增解释成准确地表面积。历史报告保留，新的事后分析应输出到独立目录并说明不是事前注册的验证。

本次完成：明确评价对象、公式、分母、无数据处理、候选阈值和通过条件；实现参考冻结、同步原始记录核验、估计位姿重建、自动评分、逐格数据和黑白地图报告。验证及真实样例见 [交付记录](../reports/evidence/terrain-workbench/mapping-acceptance-20260914/README.md)。

后续另行确认：正式任务的精度要求、其他场景的参考适用性、实物独立真值和安全事件认证。本轮不修改在线策略，不训练机器学习模型，也不启动新的三策略比较。本评价流程已经可用；这些扩展不应混为“当前系统已经通过验收”。

## 8. 算例（仅验证公式，不是实测数据）

假设 Ω 有 100 个等面积格子：

| 已重建格 | 几何达标格 | C | P | S | 解释 |
| ---: | ---: | ---: | ---: | ---: | --- |
| 80 | 72 | 80% | 90% | 72 | 已测部分达到暂定精度底线；仍需检查其他条件 |
| 100 | 40 | 100% | 40% | 40 | 看起来全覆盖，但大部分几何不准确 |
| 20 | 20 | 20% | 100% | 20 | 已测部分精度达标，其余未测；覆盖不导致失败 |
| 90 | 72 | 90% | 80% | 72 | 与第一行同分，但精度底线不通过 |
| 0 | 0 | 0% | 未定义 | 0 | 有效试验中的空白成果 |

同一份输出至少展示：验收状态、S、C_obs、C、P、RMSE_z、MAE_θ、时间预算、实际结束时间、失败情况、评价面积及表示范围外面积。

## 9. 已实现的入口与边界

`scripts/report_mapping_acceptance.py prepare` 在采集前冻结参考；`evaluate` 在采集后自动生成中文图表、中文报告、《评价汇总.json》和《逐格评价.csv》，同时保留 `summary.json`、`cells.csv`、`observations.npz` 等程序复算格式及源码校验值。图表、图例、状态和阅读版数据表头均采用中文。

- 首版入口支持 `trajectory_evaluation.py capture --raw-depth --runtime-contract` 的同步记录目录。普通前端 NPZ 不包含完整参考与运行坐标证据，不能仅凭它给出可信准确率；旧记录缺少坐标或原始图像证据时不计分。
- `compare_survey_strategies.py` 会在全部试验前按场景和起点冻结参考，并为每轮同步保存原始深度、运行坐标契约及 `mapping-acceptance-v1` 报告。自主策略提前结束时会结束该轮捕获并保留实际结束时间；不得用旧版 `survey-metrics-v1` 汇总替代这些结果。
- 参考范围目前是圆形与固定 50×50 m 场地的交集，按格心归属；矩形、多边形属于上面的通用定义，首版 CLI 尚未提供这两种形状。选择后冻结，不随已采面积改变。
- 参考使用最高解析视觉表面，在每格中央 80% 范围比较 17×17 与 33×33 采样。高度差需不超过 1 mm，坡度差需不超过 0.1°，分类必须一致。检查失败使整轮不可评价，不按被测结果删掉难点。大场地分批采样，避免一次分配全部射线。
- 当前真实样例为平面与斜盒体组成的坡道场景。曲面三角网格与解析几何不完全相同，采样收敛也不能证明不会漏掉更小结构；新场景需检查这些参考误差。
- 坐标契约来自冻结起点、实际 `survey_odom→odom` TF、运行中的 SLAM 帧配置、已审查的部署启动文件和实际机器人相机几何。声明 world/map 同轴，不从最终地图或真值轨迹拟合修正。部署启动代码改变会使现有契约检查失败，需重新审查。
- 每一帧点云必须能由同时间戳原始深度图逐位重算。用记录的**估计相机位姿**重建被测地图；同步 Gazebo 真值只用于对应检查和定位误差诊断。
- 采样约每 0.5 秒一帧，时间预算从首个同步帧开始。截止后帧不进入地图，报告首帧 S₀、最终 S、增量、丢帧数与实际末帧时刻。此示例评估记录下来的同步帧，不声称包含前端每个关键帧。
- 安全状态单独保留为未认证；即使几何达标也只显示“几何指标达标，安全尚未认证”。记录到控制失败则保留成绩并判未通过。
