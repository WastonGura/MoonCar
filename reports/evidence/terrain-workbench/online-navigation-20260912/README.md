# 50×50 米场地与实际导航显示验收

日期：2026-09-12。工作区：MoonCar-mapping，Docker `mooncar-terrain-validation`，ROS 2 Jazzy / Gazebo 8。Chrome 前端：<http://127.0.0.1:8765/>。

## 已实现

- 50×50 米任务边界；复用原世界的 50 米地面，在原中央地形之外增加 32 处分散几何物体。原静态地图与场景文件保留。
- 工作台实验改为激光在线建图定位；导航地图随观测扩展，未观测区保持未知。新起点与朝向通过初始坐标变换接入定位，Gazebo 真值仅用于验收。
- 前端显示实际 Nav2 路径、目标圆环、已行驶轨迹、导航地图范围及障碍安全余量；与深度观测地表、离线路线对照明确区分。
- 点目标采用位置到达判定，不强制用户未指定的最终朝向。总导航预算改按仿真时间与距离计算；页面失联、传感器失效、边界保护、碰撞检查仍保留。
- 新启动的导航拒绝当前地图外、未观测和障碍安全余量内的目标；失败显示具体 Nav2 错误。

## 实跑结果

1. `experiment-aefe3133cc85`：从 `(3.5, 3, 0)` 导航至 `(9, 3)`。Nav2 成功；最终定位 `(8.861, 3.020)`，Gazebo 真值 `(8.851, 3.052)`，目标误差 **0.158 米**。停车后安全速度指令实测为零。导航地图右边界从约 **12.3 米扩大至 20.0 米**，目标超过原静态地图右边界。深度档案从 3 帧增至 **77 帧**，最终 14,460 个体素点、715 个有效地表格。约 34.3 秒仿真时间，不是墙钟耗时。
2. `experiment-9e55513816f4`：复测用户原始起点 `(0.23, -2.8, 14.6°)` 和目标 `(5.3, -0.31)`。导航失败码 **208（无可行路径）**，最终定位约 `(5.131, -1.461)`；安全速度全部为零。新观测后目标格代价为 **99**，位于障碍安全余量区。场景中的中央坡台中心 `(4, 0)`、尺寸 `2.8×1.6×0.28 米`，目标落在其边缘附近。该结果不计为成功到达；不能以关掉避障或清除真实障碍使其“通过”。档案保留 143 帧、24,731 个体素点、839 个地表格。

原用户实验 `458823bf9e4f` 的日志同时出现控制器前方碰撞、控制器等待耗尽和工作台固定 180 秒墙钟超时。此次修复了时间预算与未指定终点朝向的问题；**没有证明任意目标可达、所有地形导航均通过**。

## 尚未验证或实现

50×50 米是可设置的场地范围，**不是已完成 2,500 平方米采集**。此次没有全场遍历与长时间精度验收。散布物体复用既有几何，不代表真实沙土/碎石力学。在线 SLAM 的历史深度档案位姿尚无回环修正，远距离与回环后的三维拼接精度需要单独实验。

当前为人工选导航目标后沿途采集，尚未实现根据未知区域、观测质量、风险和时间预算自主选择下一观测点。现有离线路径对照不等于该自主探测策略，也没有训练机器学习模型。硬件验收状态未改变。
