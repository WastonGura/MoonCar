## 对照条件与地图含义

同一无附加标柱 V3 场地，同一起点 `(0.5, 0, 0)`，同一 R5 / `rgbd_window` 定位，480 仿真秒预算，7200 墙钟秒采集上限，按序运行；每墙钟秒 3 帧实际 GUI 录屏。固定相同资源分配、导航与安全参数、无主动定位回访；默认地形策略仍是原策略。两轮采集期间没有离线编码，也没有改动产品代码。两次试验前、中、后的源文件和安装文件校验一致。

真值由当前 V3 碰撞地面三角网格、岩石和碎石的实际变换构建。地面共享 10 cm 高程网格已经与实际碰撞顶点核对，在固定对角线三角形内插值；岩石使用竖直射线的最高可见碰撞表面。5 cm 参考采样组成 25 cm 评价格，中心样本与实测高程格中心完全重合。真值不输入导航、定位或建图，没有用真值轨迹替换估计位姿，没有最佳拟合配准、垂直偏移修正或补洞。

实测图来自 `/mooncar/map/quality` 发布的真实高程拟合结果，单独被动记录在 `survey-map.jsonl`，不是导航代价图。视频每帧只使用实际画面采集前已收到、且仿真时间和地图源帧均不晚于显示时刻的地图；任务结束后冻结在任务结束前已收到的地图，没有把最终地图填回早期录像。最终统计与视频末帧使用同一地图快照。RPC 的 `quality-end` 另行保存，可能因发布延迟与最后已收到地图稍有差异，不把二者混用。

灰色为未观测；黄色为已采集但未获得有效高程；高度差图紫色为参考采样包含岩石/地面等多表面的混合格，这些格另计。蓝色误差表示测低、红色表示测高，色标 ±10 cm 外饱和显示，统计仍使用原值。本轮毫米级误差在这个色标下大多接近白色，精确数值见统计。高程颜色不表示通行风险；视频随车导航图仍按原有风险色标显示。现场画面的黑色直线是 Gazebo 坐标辅助网格，局部被起伏地表遮挡，不是地形接缝。

评价是单格高程平面中心与实际表面的高度差，包含定位、深度采样、局部拟合和 2.5D 表示共同影响。岩石立面、多层表面和小于 5 cm 的结构不能由这张高程格完整表达；混合检测也可能漏掉更小的结构。没有把它宣称为纯深度传感器精度。当前深度相机使用理想对齐的 RGB/depth 渲染，尚未加入经硬件标定的深度噪声、畸变、双目匹配和遮挡模型（`ros2_ws/src/mooncar_description/urdf/common/gazebo_sensors.xacro`），因此毫米级结果仅代表本次理想仿真，不能当作实车精度。本次是一次短时配对实验，不代表全场覆盖完成、长期成功率或两种策略的统计优劣。
