# R5 转向补偿设置修正与独立反馈验证，2026-10-12

**固定补偿作为通用控制的设计已撤下，动态候选已实现，但实测反馈未通过，尚未修复非平面转向偏移。正式默认仍为 `legacy`，发布批准仍为 `false`。** 本轮没有运行动态轮速执行试验，没有将旧候选或新原型发布到工作台。

## 修正了什么

旧候选将平面静态载荷推算出的前轴系数 `0.96026822178862603`、后轴系数 `1.039731778211374` 一直用于纯转向。这能用于已验证的平面诊断，不能作为不同支撑状态下的通用补偿。不能据此断言剩余 17 cm 全部由固定比例造成：弯道还存在实际轮子卸载，本轮没有进行单项补偿因果对照。

新候选运行库、模型扩展和校验器要求 `independent_laser_feedback_v1`，改为 `AdaptiveAxleAllocation`；原固定分配器仅保留历史回放源码。新 manifest 拒绝旧固定配置，模型不再写入固定前后倍率。此前未发布的固定候选镜像没有覆盖。

独立 ROS 节点只订阅过滤后的 `/mooncar/scan`、`/mooncar/imu` 和 `/mooncar/cmd_vel_safe`。激光点线匹配估计相邻扫描之间的位移，IMU 实际角速度用于配准初值；计算中去除激光安装点距车体中心 0.11 m 带来的旋转位移。没有使用轮式里程计、Gazebo 位姿、接触或载荷作为控制输入。

仅对零线速度的纯转向，根据侧向速度与实际转速的比值更新前后轮速分配。两轴系数之和保持 2，保留每侧原始平均轮速；系数限定在 0.95～1.05，变化率不超过每秒 0.02。候选使用 0.5 秒滤波、0.1 的更新增益，原平面比例只作初始化。这些属于尚未实测验证的工程控制参数，**没有证明该限幅、更新方向和增益足以消除非平面偏移**。

反馈包含整数纳秒时间、递增序号、有效标记和倍率。执行器对超时（250 ms）、未来、重复、乱序、格式错误、越界及无效反馈禁止纯转向；直行和零命令保留原路径。位置匹配必须检查几何可观测性、残差及置信指标，不能把计算出一个位移等同于可靠测量。新控制器/私有桥接退出会结束候选启动。正式启动仍受未批准门禁阻挡。

质量、惯量、几何、摩擦、地形、安全中继和公共 API 未改；继续保留此前测试的侧向 WheelSlip 接触模型和 ODE 修复，DART 库不变。WheelSlip 的名义法向力仍是原值；本轮没有实现实际载荷闭环。候选沿用 D=0，生产云台参数未切换。

## 新实测和停止结果

使用独立容器 `mooncar-r5-adaptive-turn-20261012`，原候选 Jazzy 镜像、4 CPU、6 GiB、512 MiB shm、ROS95、LOCALHOST、独立 partition、无网页端口。先做传感器影子验证：新节点只读取传感器和输出未接入执行器的候选反馈，真实轮速仍由旧固定候选执行。Gazebo 真值只在结束后的独立误差核对中使用。

| 新尝试 | 结果 |
|---|---|
| `sensor-shadow`：弯道左转 | 旧夹具引用合并安装目录，新 overlay 为分包安装，地面资源路径不存在，世界未启动；失败保留 |
| `sensor-shadow-installed`：弯道左转 | 通过包索引解析安装资源路径并逐项核对源码哈希后，以新签名、新目录运行；输入、采集及排空合格，独立反馈不合格，停止 |

共两次新尝试，其中一次成功执行静置 5 秒、转向 20 秒、停车 3 秒；运动为 20000 个 1 ms 物理步，原命令链路及加减速过程保留。左右影子对照中的右转未运行，动态执行轮数为 **0**。没有降低反馈门槛、跳过无效帧拼接轨迹或用历史结果补足次数。

本轮弯道最大真实水平位移 **171.735301 mm**，与此前固定候选现象一致；停车末秒移动为 0。这是固定候选的重新观察，不是动态补偿的效果。图片采集门槛和命令资格合格，不能把反馈失败归为此前图片断档。

运动窗口共 200 个反馈帧：

| 指标 | 数值 |
|---|---:|
| 控制器判定可靠 | 131 / 200（65.5%） |
| 侧向速度等反馈门槛未通过 | 18 |
| 配准质量失败 | 36 |
| 扫描几何不可观测 | 15 |
| 所有配准有效帧的单对位移误差最大值 | 83.028 mm |
| 控制器也判有效的帧，单对位移误差最大值 | 35.928 mm |
| 控制器也判有效的帧，误差中位数 / P95 | 5.702 / 18.103 mm |

这里的误差是每相邻扫描对的估计增量与事后真值增量之差，不是车辆末端位移。主轨迹核对在 12.1 仿真秒出现无效配准时停止，连续有效前缀为 68 对，没有跨过缺口给出完整轨迹通过结论。36 个配准质量失败中，35 个残差超过门槛；单项计数允许交集。

这说明 **当前二维激光配准不能可靠提供本场景的动态补偿反馈**。即使内部判定有效，也不保证实际测量误差足够小。仅凭这些记录不能确认是倾斜扫描平面、地表特征变化还是匹配歧义造成全部误差。本轮也没有证明传感器本身故障。

## 构建、回归和发布状态

- 全新 overlay 构建完成 8 个 ROS 包，安装的控制节点/核心/日志模块与当前源码哈希一致。
- 真实旧模型和 R5 模型 xacro 展开及 SDF 转换通过；legacy 展开逐字节相同。候选去除新增控制系统、恢复已声明的 D=0 差异后，视觉、碰撞、关节、惯量及传感器定义一致。
- 新增动态核心、真实 ROS 回调与排空、事后轨迹核对共 18 项回归；运行库/默认门禁专项 10 项。C++ 消息有效期解析严格编译及 UBSan 检查通过。
- 完整软件回归 540 项：535 通过、5 项既有跳过；控制 7、导航 10、地形 129、Gazebo 394。固件严格 C11 编译及 UBSan 通过。
- 前端 3 项通过、5 个 JS/MJS 语法检查通过；`scripts` 与 `ros2_ws/src` 的 237 个 Python 文件 AST 检查通过。

冻结结束时执行源码未改变。停止后只更新运行库 README，差异单独登记；随后重新打包 `final-package`，核对最终源码及二进制哈希，并完成真实模型静态预检。它没有获得物理执行验证，不能把影子测试结果当成该运行库验收。

## 还需要解决什么

固定倍率不能当通用补偿的问题已在新候选路径中防止；**动态补偿尚未获得可靠输入，原非平面转向偏移仍在**。下一步应先验证可以独立测量侧向移动的反馈（包括非平面情况下的测量一致性），再做动态轮速执行对照，不能拿轮式里程计当侧滑真值或继续套固定系数。

本轮没有修改正式默认、启用生产云台 profile、开展完整车辆验收或提交其他旧改动。仅关闭本轮测试容器，保留原工作台和旧证据。
