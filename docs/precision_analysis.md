# 月球车测绘精度分析

> 2026年10月19日适用范围说明：下文保留早期选型估计，未完成实测验证，不作为当前精度验收依据。栅格分辨率、采样点间距与测量准确度须分开；光照、材质、距离和设备模式的影响也需验证。当前用途、实现尺度及精度目标见[仿真用途与精度要求](simulation_validation_scope.md)。

> 针对大创项目"月球车探路导航"的传感器精度需求分析

---

## 1. SLAM 建图精度

### 1.1 为什么选 5cm 分辨率？

对于户外/月球表面导航，**5cm/像素** 的栅格地图分辨率是合适的：

| 分辨率 | 适用场景 | 说明 |
|--------|----------|------|
| 1cm | 室内精密操作（机械臂抓取） | 计算量巨大，地图文件大 |
| **5cm ✅** | **户外/室外导航** | **月球车最佳选择，平衡精度与性能** |
| 10cm+ | 大范围粗略导航 | 可能漏掉小碎石/小坑 |

月球车需要识别 15-20cm 以上的障碍物（石头、陨石坑边缘），5cm 分辨率能可靠捕获这些特征。

### 1.2 思岚 S3 传感器的理论精度

| 参数 | 数值 | 意义 |
|------|------|------|
| 测距范围 | 0.05m ~ 40m | 远距离探测足够 |
| 测距精度 | ±3cm（<10m） / ±1%（>10m） | 近距离精度优秀 |
| 角度分辨率 | 0.225° ~ 0.45° | 旋转越快分辨率越低 |
| 采样频率 | 32000 点/秒 | 是 A1M8 的 4 倍！ |
| 扫描频率 | 10Hz ~ 25Hz | 每秒 10-25 圈 |
| 激光波长 | **905nm（TOF）** | 🔑 TOF 不受环境光影响！ |

### 1.3 实际空间分辨率

在 10Hz 扫描下，角分辨率约 0.45°：

| 距离 | 相邻点间距 | 是否 ≥5cm 精度 |
|------|-----------|----------------|
| 5m | ~4cm | ✅ 刚好达标 |
| 10m | ~8cm | ⚠️ 单帧不够，多帧融合后可达标 |
| 20m | ~16cm | 🔶 靠 SLAM 多帧叠加 + 插值 |
| 40m | ~31cm | ❌ 用于障碍预判，不用于精确建图 |

> **结论**：10m 以内单帧达标，10-20m 通过 SLAM 多帧融合后可达 5cm 分辨率。20m 以外做远距离预警。

## 2. 传感器选型理由

### 2.1 激光雷达：思岚 S3（TOF）vs A1M8（三角测距）

| 对比项 | A1M8（原清单） | S3（推荐） |
|--------|---------------|-----------|
| 测距原理 | 三角测距 | **TOF（飞行时间）** |
| 室外强光 | ❌ 基本失效 | ✅ 不受影响 |
| 测距范围 | 0.15m ~ 12m | 0.05m ~ 40m |
| 采样率 | 8000 点/秒 | **32000 点/秒** |
| 防水防尘 | 无 | IP65 |
| 价格 | ~¥400 | ~¥2000-2500 |

> 月球环境模拟有强光+深阴影，三角测距在此条件下会收到大量干扰信号，TOF 是必须的。

### 2.2 深度相机：OAK-D Lite / RealSense D435i

用于**地形可通行性分析**，不是简单的避障：

- **3D 点云**：与激光雷达融合，补充近处高分辨率地形信息
- **AI 推理**：OAK-D 内置 Myriad X VPU，可跑地形分类模型（沙地/碎石/可通行/不可通行）
- **IMU**：D435i 自带 IMU，与 WT901 做冗余

| 推荐 | 深度范围 | 价格 | 特点 |
|------|---------|------|------|
| OAK-D Lite | 0.2m ~ 9m | ~¥1000 | 内置 AI 加速，功耗低 |
| RealSense D435i | 0.3m ~ 10m | ~¥2000 | 全局快门，自带 IMU |

### 2.3 IMU：WT901SDCL

- 九轴（加速度 + 陀螺仪 + 磁力计）
- 200Hz 更新率
- 用于：
  - 里程计融合（EKF/UKF）
  - 姿态估计（roll/pitch/yaw）
  - 月球模式下忽略磁力计（无磁场）

## 3. 系统架构精度链

```
┌─────────────────────────────────────────────────┐
│  激光雷达(S3)  ──→ 点云 ──→ SLAM Toolbox ──→ 栅格地图(5cm) │
│  深度相机 ──→ 深度图 ──→ 地形分类 ──→ 可通行性图层          │
│  IMU ──→ 姿态 ──→ robot_localization ──→ 里程计/EKF      │
│  编码器 ──→ 轮速 ──→ 底层里程计                              │
└─────────────────────────────────────────────────┘
```

各传感器融合后的定位精度预估：**±3~5cm**（室内）/ **±5~10cm**（室外复杂地形）

## 4. 给导师的汇报话术 🎓

> "本项目的 SLAM 建图精度设定为 **5cm/pixel**，传感器选用 TOF 激光雷达，相比三角测距方案不受室外强光和阴影影响。多传感器融合（激光+视觉+IMU+编码器）后定位精度预计在 3-10cm 范围，满足月球表面探路导航需求。"
