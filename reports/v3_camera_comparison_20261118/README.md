# V3 自主探测固定版与云台版对比

两组在同一 30 × 30 m V3 地形和同一起点 (0.5, 0, 0) 各运行一轮。每组预算 480 仿真秒，统计全部观测网格，不设起点半径。两组均使用 R5、邻域地形判断、rgbd_window 定位，启用几何退化重选和点云分段存档，无主动定位回访。按顺序运行，资源分配和录屏条件一致。

实际运行提交为 **042b89add7ff49d6ea179f10ea57bd2418cec500**，包含定位优化 0b6ad9b 和容量修复 73a5792。源文件摘要为 40338b81e8474ca4caa6c10b4df4aa639dd085684c1a077b8bca26fb91d0fde7。两轮前、之间和结束后通过安装文件核对，包含实际定位和测绘记录器模块。

固定版运行 surface_view_v2，验证进程禁用云台命令，实际相机偏航和俯仰保持约 0°。云台版运行 surface_view_v3，沿用项目当中的云台选点和恢复策略。这是两套现有自主方案的同场对照，结果同时包含视向控制、选点逻辑和实际路线差异。

## 结果

| 指标 | 固定版 | 云台版 |
|---|---:|---:|
| 实际任务时间（仿真秒） | 477.6 | 480.0 |
| 完成动作 | 28/28 | 22/23 |
| 同时点总观测面积（477.6 秒，m²） | 488.44 | 499.00 |
| 同时点有效高程面积（m²） | 432.12 | 454.12 |
| 收尾总观测面积（m²） | 488.44 | 499.88 |
| 收尾有效高程面积（m²） | 432.12 | 456.25 |
| XY 定位误差 P95（cm，实际任务窗口） | 5.37 | 8.23 |
| 共同区域高程 RMSE（cm） | 0.22 | 0.65 |
| 定位暂停 | 0 | 0 |
| 归档测绘帧 | 787 | 843 |
| 归档原始点 | 6,516,882 | 6,975,807 |
| 点云分段 | 2 | 2 |

- 固定版在剩余时间不足以开始下一动作时正常收尾。云台版跑满预算，首个云台动作完成，末次云台偏航目标在任务截止时结束。实测云台最大偏航 133.0°，俯仰达到 -15.0°。
- 两组都超过原来每会话 500 万点的上限，继续写入新帧。第一段结束至最新测绘帧间隔分别为 128.4 和 157.9 仿真秒。
- 两组均未触发几何退化重选。此次路线未复现此前的定位中断，源码核对和本轮结果还不足以验证那个停点的恢复行为。
- 有效高程面积是通过地表拟合检查的网格面积。高程误差使用两组都有效的 317.88 m² 单表面格子，统一坐标与色标。每种方案本轮各有一条轨迹。
