# 固定视向与云台视向的同任务对照

本轮最多各运行一个新世界，不搜索参数，不改默认定位、导航、回访或物理参数。比较的是共同启动准备之后，完成观察任务的执行方式，不是无云台硬件和有云台硬件的整机对比。共同的 `initial_depth_observation` 准备会使用云台，准备时间单列。

两组同用原版 V2 坡面、起点(0,0,0)、R5/independent_linear_v1、0.25ms物理步长、rgbd_window、无主动回访，CPU与内存配置不变。各自冷启动后等待实际 Nav2 生命周期与定位就绪。任务预算300仿真秒、采集墙钟预算1200秒，任务完成即可提前结束。

任务：依次行驶至(1,0)、(2.5,0)、(4,0)，向左观察90°，恢复前向观察，续行至(4.3,0)。每动作后保留相同的2仿真秒等待。固定组 `fixed_observe` 用默认0.3rad/s车体 Spin 改变视向，云台pan保持0；云台组 `gimbal_observe` 保持车头，用现有云台pan90°和pan0°，tilt同为-0.2618rad。两组均保留正常目标容差和全部运动保护，不用真值修正路线。车体位移和实测相机视向会有差异，必须记录，不能把名义同任务当成相同射线。

两套自然探索策略还有选点、评分和恢复差异，本轮不比较它们，不用任务级对照宣称策略整体优劣。

评价提前固定：完成情况；准备与正式任务耗时；观察阶段真实车体漂移和指令；总路程、倾角；定位误差、输出延迟、暂停与采集错误；实际云台视向与深度观测。地图使用同一个世界坐标矩形ROI [-1,-4,6,4]（56平方米），另列侧向目标区域[2.5,0.75,4.5,3]（4.5平方米）。沿用生产地图分辨率与拟合规则，计算观测面积、有效拟合面积及采样质量，不称地形精度。报告正式任务起始后40仿真秒的共同时间截面，以及各自任务结束值；如果某组提前结束，明示其地图停止累积。原始地图含共同准备数据，因此另列正式任务起点和增量。

固定40秒截面与最终结果共同解释，防止将更慢或更多滑移产生的额外采集直接称为更优。只运行各一次，结论限于此路线和坡面；不证明统计显著性、全场覆盖、完整上下坡或实车能力，也不代表此前更高处的视觉特征不足已经修好。
