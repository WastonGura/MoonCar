## 较早诊断版本暴露的问题（历史记录）

- **C 当时未达标。** `boundary-fix-validation-300` 的 C=58.05%、原始观测覆盖率 66.12%，任务没有用满 300 秒：五个前进目标因 15 仿真秒持续无进展被取消，随后 TF 与仿真时钟相差 2.197 秒触发安全停止。边界兜底只在普通候选耗尽时启动，该轮始终有普通候选或先行故障，因此不能声称该补丁已有现场收益。
- **非平地精度当时有问题。** 该轮总体 P=96.97%，但固定非平地分层仅 58 个有效格、15 个合格格，P=25.86%；平地 P=99.27%。非平地结果不能被总体均值掩盖。位姿相对独立仿真真值的平面 RMSE 为 0.447 m，末段最大偏差约 0.921 m。
- **二维定位链的进一步拆分。** 以首帧对齐的 `survey_odom` 未经 SLAM 修正轨迹，XY RMSE 为 2.921 m，最大 4.221 m；SLAM 将它压到 0.447 m，但末帧地图朝向比仿真真值偏约 10.1°。仿真 IMU 绝对朝向在同一离线样本首末帧与真值一致。由此应核查轮滑移、SLAM 的旋转修正与 TF 时间连续性，不能直接把仿真真值或未经校准的 IMU 全球朝向塞进正式运行。
- **离线因果诊断，不是正式成绩。** 同一 385 帧原始深度以真值位姿重建，C=57.57%、P=99.78%，非平地 P=100%；只替换平移、保留估计姿态时，C=58.39%、P=98.28%，非平地 P=63.27%。这表明当前轨迹与观测本身不足以使 C 达 80%，同时定位及朝向误差显著影响非平地精度。真值从未进入在线策略或正式评分。

截至该较早轮，共同修复包括 IMU 与深度同步姿态、地图重建与原始记录审计、真实传感器心跳、Nav2 无进展取消。额外地图边界候选仅通过单元及冻结地图离线测试，**尚未完成现场验证**。当时地形测试 71 项通过；它们不替代全栈可靠性或统计重复性。
