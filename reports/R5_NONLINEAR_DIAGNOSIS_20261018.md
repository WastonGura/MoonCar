# R5 大侧滑误差与平地旋转中心分析

85°的约2.11%误差来自当前双指数曲线在训练范围之外过早接近饱和上限；接触前缘尚未充分动员的剪切力没有被低阶近似准确保留。平地最大参考点位移增至3.194 mm，则主要是原前后轴轮速分配遇到新力曲线后，稳定旋转中心向后移动了1.594 mm。两个现象需要分别处理。

下一步优先把双指数代理换成保留接触区分布的积分实现，沿用土壤参数、轮载、摩擦上限和控制输入。平地同时记录旋转中心、质心轨迹及持续漂移；若要求围绕指定参考点转向，再独立研究适配非线性力曲线的轮速分配。当前基线及生产默认继续保留。

## 85度误差的来源

参考关系仍是上一轮依据 [Ding等2024](https://doi.org/10.1038/s41467-024-46233-8) 重建的光滑圆柱、零纵向滑移名义模型。以下数值是对本项目参考积分与代理曲线的比较，不是实测轮壤误差。

| 85°每轮结果 | 前轮 | 后轮 |
| --- | ---: | ---: |
| 参考侧向力比 q | 0.373064 | 0.365038 |
| 当前双指数 q | 0.380938 | 0.372722 |
| 相对高估 | 2.1107% | 2.1052% |
| 每轮力高估 N | 0.02813 | 0.02973 |
| 参考距饱和上限 μ−q | 0.023645 | 0.022023 |
| 双指数距上限 μ−q | 0.015771 | 0.014339 |

85°对应 `λ=tan(85°)=11.43`，已超出75°训练上界。此时参考接触区仍有未充分动员的剪切阻力，当前双指数则把力算得过于接近上限。80°误差约0.5%，到85°增至2.11%，符合这一外推偏差。

令 `u=θentry−θ` 表示从接触前缘向后的角距离，参考积分距上限的差为：

```text
D(λ) = μ − q(λ)
     = R b / N × ∫[c + σ(u) μexternal] exp(−R λ u / Ky) du
```

接触前缘 `σ(0)=0`，但黏聚力 `c=520 Pa` 仍非零，因此连续积分在大λ下有：

```text
D(λ) ~ b c Ky / (N λ) + O(1/λ²)
```

双指数的未动员部分则为 `μ[w exp(−aλ)+(1−w) exp(−bλ)]`，按指数衰减，无法保持这个渐近规律。85°时，参考未动员部分约71%来自黏聚项；约90%集中在前缘四分之一接触弧。这给出了过早饱和的具体物理位置和数学原因。相对误差最终仍会在λ趋于无穷时趋零，不能据此说越接近90°误差必然越大。

4097点原积分与独立自适应积分，在65°～88.8°检查点上的力比差小于 `4.6×10⁻⁸`；加密至32769点后小于 `6.8×10⁻⁹`。这远小于85°约0.0078的代理偏差，积分网格不是主要原因。

另做了一个事后训练范围诊断：明确把已检查过的85°点加入原训练集，用相同正权重双指数形式重新求解。85°误差降到前／后轮0.172%／0.188%，原训练和留出角度列表最大误差降到0.790%／0.808%；但0.25°～88.8°密集检查的最大误差仍为1.578%／1.530%，移到了约87.8°。因此2.11%不是双指数在85°处不可突破的下限，训练覆盖和目标函数也有影响；只补一个角度会把误差转移。该诊断消费了原留出点，不构成新的独立验收，参数没有用于车辆或替换冻结候选。

## 平地偏移为何增大

重新读取本轮4个合格平地工况，使用运动后第3～19秒的全部物理步拟合：

```text
p_reference(t) = c_world − R(yaw(t)) r_body
```

其中 `r_body` 是车体系中的稳定旋转中心。再加入独立的世界系线性漂移项，检查圆周之外是否有持续平移，并以原生机体速度作交叉核对。

| 左转平地指标 | 基线 | 非线性候选 |
| --- | ---: | ---: |
| 20秒内参考点最大位移 mm | 0.179 | 3.194 |
| 稳定旋转中心纵向位置 mm，负值向后 | −0.005691 | −1.593511 |
| 稳定参考点圆周半径 mm | 0.005691 | 1.593511 |
| 20秒内质心最大位移 mm | 12.477 | 9.303 |
| 稳定角速度 rad/s | 0.180664 | 0.180664 |

左右转得出相同的纵向中心位置。非线性候选约3.187 mm的圆周直径解释了3.194 mm的最大位移，余差包含启动瞬态。基线的0.179 mm主要包含启动瞬态，不能把它直接当作稳定圆周直径。

在上述稳定窗口，4条轨迹的固定中心拟合最大残差均小于0.001 mm；加线性项后得到的漂移速度也小于0.001 mm/s。原生速度重建的旋转中心与位置拟合一致。当前记录支持稳定中心偏移，没有显示持续累积漂移；这些数值用于分辨运动形式，不代表实物具有相应的测量精度。

质心约在参考点后方6.247 mm。旋转中心向后移动后，参考点离中心更远，质心离中心却更近，所以两种位移指标朝相反方向变化。这不是质心稳定性整体变差的证据，也不能仅凭参考点位移较小认定哪套土壤模型更真实。

## 前后轴力平衡如何改变旋转中心

原轮速分配保持不变：前／后轮转速绝对值约0.41835／0.45297 rad/s，轮缘速度为0.031794／0.034426 m/s。名义轮载分别为3.572515／3.868145 N。基线在线性区有：

```text
Fy,i = −Ni × vy,i / (10 × rolling_speed_i)
```

原分配使前后轮的 `Ni/rolling_speed_i` 几乎相等，因而在参考点附近旋转时，前后侧向力接近抵消。换成非线性曲线后，前后轮对应不同λ，软化比例不同；固定轮速分配不再保证参考点处横向力平衡。

候选稳定时前轮侧滑角代理约42.02°，后轮约39.20°，并没有处在85°区间。单前轮横向力约−0.49105 N，单后轮约+0.49105 N。若强行假设旋转中心仍在参考点，用现有曲线计算会留下约+0.01518 N的总侧向力；中心后移后，前轮横向速度增大、后轮减小，重新达到平衡。

以实际稳定角速度、轮缘速度和轮位置为输入，只求解 `Σ Fy,i(xcenter)=0`，没有把观察到的中心位置作为拟合目标：

| 同一组候选运动输入下的力平衡计算 | 旋转中心纵向位置 mm |
| --- | ---: |
| 基线线性关系 | −0.005528 |
| 上一轮文献线性关系 | −0.174821 |
| 当前双指数关系 | −1.593512 |
| 连续参考积分 | −1.587395 |
| 实际候选轨迹拟合 | −1.593511 |

该计算复现了中心偏移，直接接触记录也显示稳定总侧向力小于 `10⁻⁶ N`、总偏航接触力矩约 `−2.9×10⁻¹⁰ N·m`。质心所需的向心力与实际总纵向力约0.001395 N相符。这是使用本轮运动状态的准稳态解释，不是脱离仿真数据的独立整车预测。

尤其是，精确参考积分仍预测约1.587 mm的中心偏移，与双指数仅相差0.0061 mm。因此修复85°曲线误差，预计不会让平地参考点自动回到原位。现有轨迹也不支持把这一偏移主要归因于随机接触失稳或持续数值漂移；平地尚未新增半步长试验，不能把本轮分析扩大为全部离散误差均已排除。

## 下一步模型选择

1. **先改侧向力代理的积分表达。** 使用正的接触强度分布，按接触弧分段线性表示，再对每段的指数剪切响应作解析积分；黏聚项可直接解析计算。保持现有土壤、轮载及几何，不增加用整车位移拟合的自由参数。这样能保留单调性、饱和上限、初始切线和前缘的 `1/λ` 渐近项。分段数由相对于独立积分的收敛误差决定。单纯增加有限个指数项仍会有相同的最终渐近问题。
2. **单独处理转向中心要求。** 第一步保持原轮速分配，先确认新接触实现复现预期的非零旋转中心。以后若要求围绕指定参考点转向，再用非线性力平衡求轮速分配，并单列控制对照。不要通过减小真实侧向阻力或改土壤参数把参考点位移压零。
3. **再判断是否需要纵横耦合。** 当前参考假设纵向滑移为零，但按刚体运动与轮缘速度估算，本轮前／后轮纵向滑移代理约5.9%／13.1%。这说明把侧滑代理角直接当作零纵滑参考角有适用范围限制。先完善接触点切向速度与轮载诊断，再依据单轮组合滑移资料研究耦合；当前数据不足以识别新的耦合、沉陷或剪切历史参数。

新实现应先检查完整λ域的力、切线、饱和渐近和零轮速极限，验证数值被动性与步长收敛，再冻结后运行原平地、斜面、曲面左右转矩阵。平地增列稳定旋转中心及持续漂移指标。已经看过的85°和本轮密集网格属于回归点，不能再宣称全新留出验收。
